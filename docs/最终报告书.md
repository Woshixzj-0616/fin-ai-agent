# 金融投研智能体 · 原型报告书

版本：2026-10-07，方向 1 + 2 + 5。与当前源码对应的原型报告；报名信息、人工验收和最终提交版本由团队确认。

## 实现

原型依据原始 PDF 提取可定位字段，LLM 拆解草稿和请求受限工具，本地 Python / Decimal 计算裁决，交付 JSON、表格、页图、修改片段和执行轨迹。

方向 1 实现质押、中标、股权变动 schema、缺失和冲突，支持标签、表格及限定中标正文；可选扫描 OCR 字段需复核。方向 2 保留年度抽取，新增半年报、季报期间和单季环比，输出非经常性占比、扣非同比、背离幅度/连续性及重述线索。方向 5 新增 PE、PB、EV/EBITDA 内部一致性、引用支持性及修改前后片段。

## 架构和证据

核心为 materials、extract、words、interim、announcements、periods、finance、financial_signals、llm_check、audit_checks、tools、agent_loop、trace、main、webui。LLM 不拥有最终裁决权。事实、推论、未核实模型解释分别标明；缺毛利、费用、回款明细时只给补证框架。

证据含公司、报告版本、实际期间、原值/单位、币种/口径、调整状态、来源 SHA、PDF 页序、印刷标签、bbox。环比派生值保存所有输入 evidence_id；EPS/ROE/余额不拆差，累计数不直接环比。

两套网页共用 trace.js，展示实际通道、去重、公式、模型 JSON、门控和工具结果。核心源码、脚本及界面指纹随完整运行归档。

## 材料和实验口径

仓库历史底板 70 份年报。本轮实际回归九份年报、两份真实期间报告、两份真实公告；三类公告及扫描件另有标明的模拟样例。环境、实测结果、命令和边界见 [赛题修复验收](赛题修复验收.md) 与 results/competition_validation.json。

历史 P/R=100% 仅代表抽取值受控扰动后的程序检错结果，不证明独立准确率、公告/扫描泛化或任意研报语义能力。真实固定值回归也不等于独立盲测。24 条复签仍待真实人员完成。

本轮无服务凭证，未新增真实 LLM 联通或语义准确率结果。历史模型实验保留为历史证据，不能当作本轮服务状态。

## 限制与第三方

OCR 验证为模拟清晰扫描标签；扫描财务主链、任意复杂扫描表和未见版式仍需扩测。重述和背离只给线索，不认定造假。估值输入未独立核实行情，不是投资建议；报告在价格时点是否已公开披露需另核实。

第三方清单见 [第三方与来源清单](第三方与来源清单.md)。无授权证据的公开 PDF 再分发和协作源码整体许可仍按未核实披露。最终验收需要团队完成真实模型调用、许可核验、人工复签与独立盲测。
