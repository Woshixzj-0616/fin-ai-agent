## 原目标

1. 在仓库根目录建立独立 `web/`，把工作台 HTML、CSS 和前端壳层 JS 从 `agent/webui.py` 中分离出来。
2. 提供只读静态服务 `/app/`，支持 HTML、CSS、JS 的正确 MIME、缓存头和受控路径解析。
3. 建立任务输入、运行栏、阶段、轨迹、结果、追问六个可独立定位的界面区域。
4. 建立单状态容器、纯视图渲染和后续 SSE/API 模块的目录边界；本批不接真实数据流。
5. 保持 `/`、`/index.html`、旧页面、旧 API、B1 事件契约和 B2 API 完全兼容。
6. 用自动化测试、Node 语法检查和桌面/移动截图证明资产可独立调试，且旧入口没有回归。

本批结束时，`/app/` 是可供 B4 接线的工作台壳，不是伪装成可用的完整实时页面。真实提交、SSE、轨迹和结果绑定在 B4 完成。

## 用户可观察结果

- 浏览器访问 `/app/` 可以看到实际工作台骨架，而不是营销首页或空白页。
- 桌面端为左侧运行栏 + 右侧主工作区；窄屏为顶部状态条 + 可展开运行抽屉。
- 查看页面源码时，HTML 不含内联 CSS/JS；样式和脚本都是可单独打开、检查和缓存的 `/app/...` 资源。
- 旧 `/` 页面保持原样，旧接口仍可调用。
- B3 页面尚不发起分析、不显示伪造进度；B4 接入真实 `POST /api/runs` 和 SSE。

## 接口与契约

### 静态路由

| 方法 | 路径 | 结果 |
| --- | --- | --- |
| `GET` | `/app`、`/app/` | `200`，返回 `web/index.html` |
| `GET` | `/app/css/{name}.css` | `200`，`text/css; charset=utf-8` |
| `GET` | `/app/js/**/*.js` | `200`，`text/javascript; charset=utf-8` |
| `GET` | `/app/其他不存在文件` | `404` |
| `GET` | `/app/../...`、编码后的越界路径 | `404`，不得读取 `web/` 外文件 |

路径规则：

- `web/` 根使用绝对路径常量 `WEB_ROOT`。
- URL 先 `unquote`，再拒绝 NUL、反斜杠、绝对路径和 `..` 段。
- 解析后必须用 `resolve()` 和 `relative_to(WEB_ROOT)` 双重校验。
- 不提供目录列表、不猜测扩展名、不读取符号链接逃逸目标。
- HTML：`Cache-Control: no-store`。
- CSS/JS：`Cache-Control: public, max-age=300`。
- 所有响应包含正确 `Content-Type` 和 `Content-Length`。

### DOM 壳层

`web/index.html` 必须提供稳定节点，供 B4 直接接线：

- `main[data-app="fin-workbench"]`
- `aside#run-sidebar`
- `button#run-sidebar-toggle`
- `div#run-list`
- `section#workspace`
- `form#task-form`
- `div#stage-view`
- `section#trace-view`
- `section#results-view`
- `section#ask-view`
- `div#status-region`
- `div#error-region`

DOM 契约只定义容器和可访问名称，不在 B3 创建真实运行数据。页面首次渲染显示“尚无运行”“尚未开始分析”等空态，不显示百分比和假进度。

### 前端模块

- `run-state.js` 是唯一状态容器。
- 初始状态固定为：
  - `runs: []`
  - `currentRunId: null`
  - `currentRun: null`
  - `events: []`
  - `result: null`
  - `connection: "idle"`
  - `error: null`
- `views/task.js`、`views/trace.js`、`views/results.js` 只接收 `root + state` 并渲染，不直接发请求。
- `main.js` 只创建状态容器、订阅状态、调用视图和绑定运行栏展开按钮。
- B4 新增的 `api.js` 是唯一 HTTP 客户端，`stream.js` 是唯一 SSE 客户端；本批不提前复制请求逻辑。
- `web/index.html` 只能通过 `<link>` 和 `<script type="module" src="...">` 引用本地资产。

### 视觉契约

- 桌面端两栏：左侧运行栏固定 `288px`，右侧 `minmax(0, 1fr)`。
- 窄屏断点 `900px`：改单列，运行栏默认隐藏，由 `#run-sidebar-toggle` 控制 `body[data-sidebar-open]`。
- 使用中性底色，正常状态蓝绿、警告琥珀、失败红色；颜色不是唯一状态信号。
- 卡片圆角不超过 `8px`；不使用大面积渐变、装饰圆球或营销式首屏。
- 所有文本在 `390px` 宽度下不得溢出、重叠或遮挡后续内容。
- 图标按钮使用可访问名称；没有本地图标资产时，B3 使用带文字的明确按钮，不手绘临时 SVG。

## 反向检查

### R1：静态路径越界必须失败

失败注入：

```text
/app/../agent/webui.py
/app/%2e%2e/agent/webui.py
/app/%2e%2e%5cagent%5cwebui.py
```

期望结果：全部 `404`，响应不得包含 `class Handler` 或任何仓库外文件内容。若返回源码，说明路径门失效。

### R2：旧首页不能被新壳替换

失败注入：GET `/` 和 `/index.html`，与原 `PAGE` 做字节级比较。

期望结果：两者仍返回原页面。若返回 `web/index.html`，说明兼容线被破坏。

### R3：外部依赖必须被拦住

失败注入：扫描 `web/` 中的 `http://`、`https://`、`//cdn`、外部字体和远程图标引用。

期望结果：零命中。若页面依赖网络资产，说明离线可复现门失效。

### R4：内联资产必须能被检出

失败注入：检查 `web/index.html` 中的 `<style>`、无 `src` 的 `<script>` 和非空 `style=`/`onclick=`。

期望结果：零命中。若内联渲染仍存在，说明资产剥离门失效。

### R5：语法门本身必须能失败

失败注入：把 `const value = ;` 喂给同一个 Node 语法检查命令。

期望结果：命令非零退出。若坏语法仍通过，说明语法门是恒真。

### R6：响应式门必须能失败

失败注入：删除或破坏 `responsive.css` 中的 `900px` 断点，在 `390px` 视口检查布局。

期望结果：出现横向滚动或运行栏遮挡主区。若没有任何变化，说明截图/视口检查没有真正覆盖移动端。

## 回滚

- 触发条件：`/app/` 导致旧页面、旧 API 或服务器稳定性回归；静态路由出现路径越界；移动布局在竞赛演示宽度不可用。
- 回滚方式：移除 `/app/` 路由接线和 `web/` 静态目录，保留 B2 的旧页面与 API；B3 文档和测试可单独删除。
- 回滚后验证：全量测试恢复为 B2 的 230 条通过、1 条设计跳过；`/`、`/index.html` 和旧 API 正常。
- B3 不修改数据处理路径，因此回滚不需要迁移运行目录、数据库或结果文件。
