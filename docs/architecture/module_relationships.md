# 六个模块的关系

六个模块围绕同一份年报协作，但每个模块回答的问题不同：

1. `part1_business`：公司做什么、靠什么经营、业务结构如何变化。
2. `part2_profit`：利润从哪里来、变化是否可持续、利润质量如何。
3. `part3_assets`：资产结构、资产质量、经营效率和潜在减值压力。
4. `part4_cashflow`：利润是否兑现为现金、现金来源和去向是否健康。
5. `part5_solvency`：债务结构、偿债压力、流动性和资金安全边界。
6. `part6_disclosure`：披露可信度、特殊事项、风险信号和需要追问的地方。

模块之间允许互相引用事实，但不直接覆盖彼此的专业结论。总入口以后可以在结果层做交叉提示，例如“利润增长但现金兑现弱”，而不把这句话硬塞进某一个模块的内部流程。
