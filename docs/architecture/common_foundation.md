# 共同基底的最小范围

共同基底是模块的工具箱和生命周期，不是把所有模块改造成同一个分析模板。

## 第一版必须提供

| 能力 | 统一提供的最小信息 | 专业模块可以自由决定的部分 |
|---|---|---|
| 报告身份 | 文件名、哈希、报告期、页码 | 重点章节和阅读顺序 |
| 原文读取 | 按页读取、关键词检索、出处定位 | 检索词、证据筛选和解释 |
| DeepSeek | 模型、超时、请求记录、响应记录 | 提示词、调用次数、角色分工 |
| 计算 | 输入、公式、单位、结果和异常 | 指标体系、阈值和专题计算 |
| 证据 | 原文片段、页码、事实状态 | 证据权重和模块判断 |
| 运行记录 | 运行 ID、模块版本、状态、错误 | 中间步骤和模块内部草稿 |
| 结果外层 | 模块名、版本、状态、来源入口 | 所有专业结果字段和版式 |

## 不在共同基底强行统一

- 不统一六个模块的分析步骤。
- 不统一每个模块的指标数量和阈值。
- 不把所有输出压成几句摘要。
- 不把模块内部提示词、追问策略和异常判断抽成公共模板。

统一入口只要能让模块取得工具、保存过程并交回结果即可。
