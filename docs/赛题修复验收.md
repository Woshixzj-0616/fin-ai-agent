## 验证结果

机器记录在 [competition_validation.json](../results/competition_validation.json)，测试原始输出在 [competition_test_results.txt](../results/competition_test_results.txt)。

- 自动回归 **153 项通过，0 失败、0 错误、0 跳过**。包括既有 125 项与新增 28 项；其中固定九份年报集成回归已实际运行。该数量为测试方法数，不是字段准确率。
- 财务快照包含 **9 份年报 + 2 份真实期间报告**，合计 **365 条证据**（新增期间报告 40 条）、122 行本期指标。材料台账 72 条包含历史 70 份登记，不能表述为本轮全量重跑 72 份。
- 六组公告样例：两组真实、三类模拟、一个模拟扫描件。真实中标的预估金额及全部 OCR 字段保留复核状态。
- 四条补充审计样例：PE 纠错、页序超界确认错误、原页字段支持、未知编号体系转复核。它们是功能验收样例，不是独立盲测。
- Python 源码语法、静态网页 JS 与 webui 内嵌 JS 检查通过；CLI 公告和审计入口可跑。
- 浏览器实际操作已验证：公告字段定位原页与高亮，PE/引用显示，轨迹展开；扫描公告上传显示 5 条复核；半年报 + 一季报上传得到 40 条证据和 Q2 环比；两套问答均返回一季度精确期间及 10.54% 同比。未发现浏览器 error/warn。
- 计划书及两份模拟 PDF 的全部页面已经渲染查看，排版可读。测试输出含 PyMuPDF/运行库的非致命提示及模拟 HTTP 异常夹具警告，不影响通过结果。

最新“披露同比一致”计数和源码/输出指纹以机器记录为准。未提取到披露同比时展示“未核对”，不能算作一致；抽取标记为空也不代表公司无业务风险。

## 复现入口

在仓库根目录执行，详细配置见 [运行说明](运行说明.md)。

```bash
python3 -B -m unittest discover -s agent -p 'test*.py'
python3 -B scripts/setup_ocr.py
python3 -B scripts/build_competition_demos.py
python3 -B scripts/site_build.py --codes 600519_2023,600519_2024,600519_2025,000858_2023,000858_2024,000858_2025,600887_2023,600887_2024,600887_2025
python3 -B agent/main.py audit --claims data/demo/audit_claims.json
python3 -B scripts/site_build.py --use-existing
python3 -B agent/webui.py
```

新环境需先安装 `requirements.txt`，取得已登记的固定年报，并配置 OCR 数据，否则相关真实集成/OCR 测试会明确 skip。静态演示运行 `python3 -m http.server 8766 --directory docs`。

原始真实新增样例的 URL、SHA-256、页数及许可状态见 [样例来源台账](../data/demo/sources.json)，主材料台账在 `data/agent/materials.jsonl`。
