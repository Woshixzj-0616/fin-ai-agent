## 页面和服务

backend/cashflow_workbench.py 是模块四自己的 FastAPI 服务，不挂载 8007 后端，不反向代理到其他端口。浏览器前端使用同源 /api 请求。页面由 frontend/cashflow.html、frontend/cashflow.css 和 frontend/cashflow.js 构成，不参与 V3.0.1 的 React 页面构建。

页面将结果按五个板块展示：现金全貌、利润到经营现金、经营现金收付、投资现金、筹资与现金余额；另有同比贡献桥、经营/投资/筹资及利润勾稽、专题、金额校验、复核提示和模块四追问。板块中的事实卡会同时展开直接引用事实和相关计算使用的事实，计算、原文摘录和来源页码均可回查。

上传 PDF 后，模块四分析仍使用自身的专业选页、提示词、事实登记、现金流专用计算和提交金额校验。页面分开展示运行状态、分析完整度、板块状态、复核提示和提交未通过原因。文字或金额匹配只作为来源校验信息，不会显示成专业结论已经证实；未披露值保持为空。

追问每一轮都会附上模块四专业提示、当前完整结构化结果和近期追问历史。模型可调用本次年报的页内搜索和物理页读取工具；读取页码会归入该追问记录并更新本次运行的页码。
