## 模块身份与调用

- 模块 ID：`assets`
- 当前专业模块版本：`v3.3.2`
- 入口：`backend/modules/assets/entry.py` 的 `run(context)`

- 所需公共能力：V3.0.1 `ReportContext` 的 `pages`、`search_pages`、`read_page`、`call_model`、`record_tool`、`record_calculation`、`progress`、`save_artifact`

## 结果映射

模块入口返回 `{"result": <完整分析>, "trace": [], "read_pages": [...]}`。`result` 保留模型的所有有效字段，并增加核验后的事实与程序计算；前端应按五个专业板块分别展示：

| 结果字段 | 页面用途 | 建议呈现 |
| --- | --- | --- |
| `summary` | 资产质量总览 | 顶部摘要，保留模型原文 |
| `asset_map` | 整体资产占用与结构变化 | 资产结构、两期金额和变化；有数据时再画图 |
| `receivables` | 应收及其他资金占用 | 总额/准备/净额、账龄、集中度、回款及限制 |
| `inventory` | 存货结构与减值 | 按公司实际分类呈现变化、准备和周转 |
| `long_term_assets` | 长期资产和项目 | 固定资产、在建工程及重要资产专题 |
| `efficiency` | 周转与收入对应资产占用 | 指标、口径、公式及缺项 |
| `findings[]` | 可展开的单项发现 | 标题、判断、证据、计算、解释、限制 |
| `limitations[]` | 全局限制和未披露项 | 明确缺什么资料及其影响 |
| `handoff[]` | 给其他分析模块的待核查线索 | 对应事实、出处、接收方向和具体问题 |
| `facts[]` | 可展开的事实底表 | 原始科目、金额、期间、范围、总额/净额及 PDF 引文 |
| `calculations[]` | 可复核的计算底表 | `calculation_id`、公式、输入事实 ID、输出和适用限制 |
| `evidence_notes[]`、`evidence_reference_notes[]` | 引用核对状态 | 区分摘录匹配、引用待查及表格行列语义仍待人工确认 |

`asset_map` 等专题正文可因公司和披露差异而采用对象、数组、表格行或叙述，不能强迫不同公司输出相同专题。前端需对这些字段做可读的通用 JSON 渲染并保留未知字段；数组逐项展示，对象保留键名与层级。任何板块缺失时显示“本次未提供该板块”，不得把缺失解释为零或无风险。

`findings[]` 的建议字段为 `title`、`conclusion`、`evidence_refs[]`、`calculation_refs[]`、`analysis`、`limitations[]`。每个来源引用用 `fact_id` 和 PDF `page`；计算引用用已登记的 `calculation_id`。`citation_audit.status` 只说明引用能否连回本次事实/页码，不等于模型结论正确，也不代表复杂表格行列已人工确认。

## 事实和计算的可追溯结构

- 事实 ID：`assets-f0001` 等。`evidence[]` 保存物理页 `page`、原文 `quote`、用途 `role` 和 `quote_matched`。
- `calculation_ready` 只有在引文、数字、科目、单位、期间、币种和合并范围均有支持时才为真。`row_column_semantics_independently_verified` 明确保留为 `false`，前端不能显示成“已审计”。
- 计算 ID：`assets-c<摘要>`。每项保留公式、输入事实 ID、输入金额、期间、范围、币种、结果、单位和说明。
- 周转率使用相同范围和期间两端平均余额；期间起始日按其前一日的期末资产匹配期初余额（年报常见的 1 月 1 日期间起点对应上年 12 月 31 日）；应收周转以营业收入近似赊销额时必须显示该限制；天数按 365 日并标明约定。
- 总额、准备、净额不会合并成单个数字；准备列为负数时勾稽使用绝对值，并保留差额。
- 未通过核验的事实仍可留在 `facts[]` 供人工查看，但 `calculation_ready=false`，不能用于程序运算。

## 运行方式

双击任务目录中的 `启动模块三工作台.cmd`，或运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\启动模块三工作台.ps1
```

工作台网址为 `http://127.0.0.1:8103`。服务使用任务目录中的 `.env` 保存页面新配置；任务目录未配置时只读使用本机 V3.0.1 配置作为兼容来源。新上传的 PDF、模型调用记录、结果和追问写入 `data/模块三工作台/<run_id>/`，日志写入 `logs/`，均由 `.gitignore` 排除。早期 `data/开发运行/` 只作为只读历史来源。
