## 页面板块

页面将结果按以下区域展现，并保留原始 JSON 下载和展开查看：

1. 总览与报告身份、分析状态、重点发现。
2. 资产结构；应收及资金占用；存货；长期资产；经营效率五个独立专题。
3. 重点发现及对应事实编号、计算编号、PDF 页码和引用状态。
4. 事实底表：年报科目、数值/单位、期间、范围、总额/净额基础、逐条摘录及口径验证。
5. 程序计算：公式、输入事实、输出和限制。
6. 依据与限制、后续模块交接、运行信息和提示词版本。
7. 本模块追问：每次请求附带专业指导和当前完整结果，最多三轮工具交互；支持年报搜索、原文读页、候选事实登记和程序计算。

事实卡片将摘录状态标成“原文摘录文字匹配”，不会写成“结论已证实”；表格行列语义仍以核对字段显示。缺失值显示“未提供”，不会替换成 0。

## 服务接口

- `GET /api/health`：模块版本、端口、模型配置状态。
- `POST /api/settings/deepseek-key`：只保存到任务03 `.env`，页面不回显 Key。
- `POST /api/runs`：接收一份不超过 25 MB 的文字型年报 PDF，执行模块三入口。
- `GET /api/runs`、`GET /api/runs/{id}`：本机历史及完整结果。
- `GET /api/runs/{id}/pages/{page}`、`GET /api/runs/{id}/file`：页码原文回查和本次上传的 PDF。
- `GET/POST /api/runs/{id}/followup`：本模块追问和对话历史。

新运行将 `run_status` 与 `analysis_status` 分开：运行可结束而分析处于部分完成、资料不足或待复核。中断、模型错误会保留已写入的事件和 artifacts。

早期 CLI 结果从 `data/开发运行/` 以只读方式纳入历史页；已保存的完整提取页面可用于历史结果回查。旧记录没有保存上传 PDF 时，“打开 PDF”不可用，但页码文字回查可用。旧记录的追问及新增资料写在新的 `data/模块三工作台/<run_id>/`，不写回旧产物目录。

## 启动与停止

- 一键启动：`启动模块三工作台.cmd`。
- PowerShell 启动：`启动模块三工作台.ps1`。
- 地址：`http://127.0.0.1:8103`。
- 服务进程在后台运行；本地运行数据和日志分别留在任务目录。端口已被其他服务占用时启动脚本会停止，避免浏览器连到错误版本。
- 需要停止服务时，在 PowerShell 查看 8103 监听进程，再按用户实际使用状况结束对应进程；不要终止其他端口的工作台。
