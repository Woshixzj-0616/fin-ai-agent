# V3.1 模块一：业务与经营背景分析

状态：已接入产品流程，真实年报人工验收尚未完成。V3.1 是 V3.0 的独立工作副本；本实施记录只适用于 V3.1。

## 为什么先做这一模块

在读利润、现金、资产和债务之前，先弄清公司经营什么、收入来自哪里、业务怎样变化。它给后续分析提供业务口径和核查问题。来源是现有教材阅读笔记中“按业务拆收入、有同口径量价数据时再拆销量和价格、识别行业专属字段”的要求；参考笔记记录的书页为 624、692—694、742。

本模块只建立经营事实和问题清单，不直接判断盈利质量、资产质量、现金兑现或偿债能力。年报没有披露时会显示缺口，不用行业常识补齐公司自己的事实。

## 用户会看到什么

1. **业务画像**：公司主要经营什么、按年报披露怎样获得收入。
2. **经营链条**：产品、服务、生产交付、渠道或客户等已披露环节，各环节有页码和原文摘录。
3. **收入结构**：产品/业务、地区、销售模式等拆分口径分组展示，显示年报原始单位、期间、上期对照和毛利率（如有）。
4. **经营变化与驱动因素**：区分年报披露事实、公司自己的解释、分析推断和未查明事项。
5. **经营依赖与重大变化**：展示年报披露的客户、供应商、产品或地区集中度，以及并购、重组、投产等变化。
6. **交给后续模块继续查**：把模块一发现的缺口转成下一步具体问题，例如收入增长是否转化为利润、应收或存货是否同步变化。

## 模块内部的工作顺序

| 步骤 | DeepSeek 负责 | 程序负责 | 交付 |
| --- | --- | --- | --- |
| 1. 确认报告 | 从年报定位公司、期间、合并/母公司口径和币种 | 拆页、保存全文索引、记录任务版本 | 报告身份和口径 |
| 2. 了解业务 | 阅读主营业务、经营讨论、业务概要等章节 | 搜索全文、读取指定 PDF 页 | 业务画像和披露的经营链条 |
| 3. 拆收入 | 识别产品/业务/地区等表格口径，并保留原始名称和单位 | 保存原始值、期间、指标名、页码和摘录 | 分口径收入结构 |
| 4. 解释变化 | 摘录销量、售价、结构、产能、订单或公司解释；推断必须标明 | 校验页码和原文摘录；对满足条件的数据复算 | 变化因素及证据边界 |
| 5. 交接问题 | 提出后续模块要补查的具体问题 | 将完整结果保存在该任务中 | 可继续执行的核查清单 |

每次模型调用都会重新附上本模块任务规则、输出字段、当前 PDF 页和必要的任务摘要；不假设 DeepSeek 保留前一轮上下文。

## 当前数据和计算规则

- 每个事实可带最多 3 个 PDF 页码；程序删除本轮没有实际读取的页码。
- 短摘录会与 PDF 提取出的原文按去空白后的文字逐字比对，界面显示“已匹配”或“待核对”。
- 原始数值、单位和报告期间按年报保留，不在保存字段中换算。
- 收入差额和变化率由程序使用 Decimal 计算，不让模型自行算。
- 当前支持人民币“元、千元、万元、亿元”之间的精确换算；美元、港币或其他未支持单位不计算。
- 普通变化率要求本期和上期数值、单位、期间齐全，且比较期间不同。上期基数为零或负数时不显示普通同比百分比。
- 收入占比额外要求分部指标名与收入总额指标名相同、报告期间与总额相同、分部无不可比说明，且人民币单位可换算；任一条件不满足就显示“未计算”。
- 不同收入拆分维度分组展示，不跨组求和；未披露不能写成零。

## 怎样用教学资料逐步改进

我们不通过给 DeepSeek 做微调来“训练”这一模块。第一版把教学方法整理成模块提示词、字段规则和程序校验；改进依赖团队提供的真实年报人工答案：

1. 选一份年报，团队成员手工记录公司业务、分部收入、报告页码、原文、期间和单位，形成这份文件的人工标准答案。
2. 用 V3.1 跑同一份材料，把模型结果逐项与标准答案对照，标记错公司/期间、漏分部、错单位、错页码、假摘录、混淆拆分口径和无依据因果解释。
3. 把错误分为三类：提示词或字段缺陷、程序规则缺陷、PDF 提取/页码缺陷；分别修提示词、程序或材料处理逻辑，避免只改一句提示词掩盖程序问题。
4. 用另一份未参与编写的年报复查修复是否有效；保留输入文件哈希、提示词版本、运行结果、人工答案和差异记录。
5. 修复后重跑旧样例，检查新提示词是否让旧案例退化。只有这些记录稳定后，才把模块一版本冻结，再开始模块二。

## 当前实现边界

- 依赖可提取文字的 PDF；扫描件 OCR、跨年多报告联合趋势和同行同口径比较尚未接入。
- 产品收入按总收入占比计算需要年报口径与总额指标名称一致；严格条件会使部分年报显示“未计算”，这是有意的保守处理。
- 模型负责识别表格语义和提取字段，程序目前能验证页码是否读过、摘录是否匹配和计算是否满足基础条件；它不能证明模型选对了表格或正确理解了分部重组。重要口径仍需人工复核。
- 尚无冻结样例和完整人工评分，因此目前不能据此宣称模块分析准确或达到比赛标准。
