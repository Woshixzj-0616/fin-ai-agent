# 模块一 V3.1.2 改进方案与执行记录

状态：代码、界面和本地检查已完成；真实 DeepSeek 联调及人工标准答案复核仍待在可联网环境完成。

## 1. 本版目标

模块一是财报分析能力底座，先回答公司经营什么、收入怎样形成、经营背景和变化是什么，以及后续模块要追查什么。它不替代盈利能力、资产质量、现金流和偿债模块，也不接收研报草稿做交叉核查。

V3.1 的已知问题是：提示词规定了顺序，但程序主要让模型在一个回答里同时抽取、解释和总结；收入占比只使用一个总额，遇到“主营业务收入”分项和“营业收入”总额会留空；分项最多保留 12 项；程序完成状态没有明确告诉用户哪些内容有出处、哪些只命中了候选页。

## 2. V3.1.2 的模块一流程

1. **读取和索引年报**：沿用全文提取、PDF 页码和按需检索；只支持可提取文字的 PDF。
2. **程序预检主题**：分别搜索业务模式、行业背景、战略/竞争、收入构成、客户/供应商与风险、重大变化等主题。每个主题最多把候选页补入模型上下文；候选页是定位线索，不算已证实事实。搜索未命中不会显示成“年报未披露”。
3. **DeepSeek 第一阶段：事实提取**：独立提示模型确认公司和报告口径，摘录业务链条、收入分项、明确披露的各类收入合计、年报同比、行业/战略陈述、依赖、风险和重大变化；此阶段不做经营归因。
4. **DeepSeek 第二阶段：解释与交接**：重新把模块一规则和第一阶段的结构化事实一起提供给模型，分析变化、写有限解释、保留其他可能原因，并形成后续模块问题。程序没有假设模型记得上一轮。
5. **程序复核**：再次检查页码是否在本次读取范围内、摘录能否在对应 PDF 页找到、币种/范围/期间/收入指标是否一致；满足条件才计算收入占比和年度变化。
6. **覆盖检查与展示**：结果单独显示六类内容：业务模式、行业背景、战略与竞争、收入结构、经营依赖与风险、后续模块问题。对有可回查引用、引用待核、只命中候选页和检索未命中分别标状态。

程序匹配原文，只能证明这段文字出现在该页，不能证明模型选对了表格或因果关系。页面把“流程完成”与“分析仍待复核”分开显示。

## 3. 收入处理规则

- `revenue_total` 保留主要收入总额；`revenue_totals` 另存年报明确披露的其他合计口径，例如营业收入、主营业务收入和营业总收入。
- 每条分项按年报指标名和拆分维度保存，最多 80 项；前端每页显示 20 项，避免长表难以查看。
- 分部占比只找同一收入指标的分母。指标、期间、币种、合并/母公司范围、人民币单位和两边引用都要匹配；分项与合计可以引用不同 PDF 页。
- 不把类别分项自行相加制造新的总额；只有报告明确披露的合计才可作为分母。主营业务收入不得除以合并营业收入。
- `reported_yoy` 原样保留年报披露的同比；“程序复算同比”独立展示，不用模型补造上期绝对额。
- 普通同比只对相邻年度、可比较范围和分类、支持的人民币单位计算。零或负基数、期间不清楚、范围不一致或明确不可比时留空并说明。

## 4. 修改范围

- `backend/deepseek_agent.py`：固定主题预检、事实提取/解释两阶段、单独的追问上下文、引用与收入校验、覆盖状态。
- `backend/prompts/模块一_业务与经营背景_v2.md`、`模块一_事实提取_v2.md`、`模块一_分析与交接_v2.md`、`模块一_追问_v2.md`：每次模型调用分别携带完整任务边界和阶段要求。
- `backend/app.py`：FastAPI 版本号、阶段进度与提示词版本更新。
- `frontend/src/V2Workbench.jsx`、`styles.css`：覆盖卡片、出处状态、行业/战略/风险内容、收入分母证据、披露同比与复算同比分列、分项分页和待复核状态。
- `frontend/index.html`、`frontend/src/App.jsx`、`ReviewWorkspace.jsx`：显示 V3.1.2 版本。
- `启动V3.1.2.ps1`、`打开V3.1.2工作台.cmd`、`frontend/vite.config.js`：独立使用 8004 端口。
- `tests/test_module_one_v2.py`：固定口径、分页数量、跨页分母、范围不一致和分阶段调用回归。

## 6. 版本与已知边界

- V3.1.1 是原 V3.1 目录的原样保留版，继续使用 8003 端口。
- V3.1.2 是独立副本，使用单独 Git 仓库/分支、本机 `.env`、8004 端口和新建的运行数据库；不与 V3.1.1 任务记录共用。
- 两个版本都还需要用人工答案检查模型是否选对表格、分类和经营因果。V3.1.2 不据此宣称达到比赛准确率。
- 扫描件 OCR、行业外部数据联网补充、同行对标、复杂多页表格自动完整性证明及跨年趋势暂不在本次实现范围。
- 收入分项保留上限为 80 项；超过时提示不完整，不把截断结果当成完整构成。
