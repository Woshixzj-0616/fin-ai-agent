# 模块六专业方法与来源

本文件为模块六专业提示词和人工核对提供出处。年报原文决定公司事实；方法材料只用于提出检查问题和解释判断边界。

## 教材阅读

### 用户提供的《一本书掌握财务技巧》（合订本）

本任务复核物理第 525—526、535—538 页：

- 525—526：从资金、收入、利润及交易循环入手，回到实际经济业务，循线检查报表项目的形成。
- 535—538：审计意见、意见基础、审计报告其他段落各有不同含义；审计意见不是整份年报所有文字的万能保证；关键审计事项、强调事项和其他事项需要与原文及具体科目联系。
- 书中口语化描述用于零基础读者建立概念，不能替代现行审计准则的准确用语。

原件由用户提供，本工作区不复制书籍 PDF。

### 关键专业区别

| 事项 | 本模块对用户的解释 |
| --- | --- |
| 无保留审计意见 | 对财务报表整体发表的意见；不意味着经营无风险或年报其他信息全部经鉴证 |
| 非无保留审计意见 | 按意见基础解释错报/证据限制的性质与范围，不由模型自行重下审计意见 |
| 关键审计事项 | 本期审计中的重要关注点，描述原因和审计应对，不构成单项意见或已经发生错报的证明 |
| 强调事项 | 提醒理解已在报表恰当列报事项；准则要求指出不改变审计意见 |
| 其他事项 | 与理解审计工作、审计责任或报告有关的信息，不能和“其他信息”混称 |
| 其他信息 | 年报中除报表与审计报告以外的信息，和财务报表审计意见的鉴证范围不同 |
| 会计政策/估计/差错 | 逐项识别披露名称、适用期间和处理方式，不仅凭模型猜测归类 |
