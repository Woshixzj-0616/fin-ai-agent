# 模块六开发运行说明

## 专业入口

`backend/modules/disclosure/entry.py` 提供共同接口 `run(context)`，模块 ID 为 `disclosure`。它使用 `ReportContext` 的模型调用、全文检索、原文读取、运行事件、计算记录和进度能力，返回完整模块六专业结果。

本目录已增加只供本工作区使用的 disclosure 注册入口和独立工作台。独立工作台默认运行模块六，不调用 8007 服务；原来的 `run_local.py` 仍可用于命令行单次运行。

## 独立工作台

双击项目根目录的 `打开模块六工作台.cmd`，或在本目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\启动模块六工作台.ps1
```

工作台地址 `http://127.0.0.1:8106`。启动器会检查端口占用并验证服务模块版本；若 8106 属于其他服务，不会停止该服务。前端代理、浏览器页面和本工作台后端均固定连接 8106。

本工作台使用**本目录 `.env`**。首次启动会从 `.env.example` 建立本地配置；也可以在页面配置 DeepSeek Key。不要将 Key 放进代码、提交或日志。PDF、SQLite 记录、运行检查点和日志在本目录 `data/app/`，与其他版本隔离。需要 Python 3.12+ 与 Node.js。

## 独立命令行运行

以下命令同样使用本任务自己的 `.env`，上传年报和结果留在当前中文任务工作区：

```powershell
$Python = 'D:\ChatGPT项目\金融AI智能体\.venv\Scripts\python.exe'
$Report = 'D:\ChatGPT项目\金融AI智能体\data\raw\600887_伊利股份_2024年年度报告.pdf'
& $Python -m backend.modules.disclosure.run_local --pdf $Report --config '.\.env'
```

默认专业运行目录：`data/开发运行/模块六/<run_id>/`。网页运行的上传 PDF、任务数据库、对话和日志位于 `data/app/`。每次模块运行包含 `manifest.json`、`events.jsonl`、`result.json` 和模型/页面/工具/计算附件。相关本机目录已在 Git 忽略范围内，只供本机查看。

交互预算由 `FINLAB_DISCLOSURE_MAX_MODEL_TURNS` 调整，默认 18，允许 3 至 30 次工具模型交互；其中最多 6 次用于搜索/读页，其余留给结构化提交和修正。到达上限时会要求模型基于已经读取的材料形成结果，并保留未完成主题。工具提交和直接 JSON 返回都执行同一完成门禁；结束门禁拒绝或结果标准化后仍有关键缺项时，检查点记为 `partial`，不能以完整 JSON 绕过。访问失败、认证失败、限流、余额不足和服务错误使用不同安全提示。提示词要求对每次 API 调用明确提供工作指导和已有上下文，不依赖服务器记住前次请求。模型调用异常时若检查点已有概要、专题、影响或计算，`result.json` 状态记为 `partial` 并保留现有检查点；CLI 会打印 `partial` 和结果目录，并以退出码 2 表示需要续办。

## 输出位置和交接

- 原始模块结构：`result.json` 中 `result`。
- 页面及工具访问：`result.read_pages` 与 `events.jsonl`。
- 可核验摘录：各专题的 `evidence`，包含 `verification` 状态。
- 计算：`result.calculations` 与相应 `calculation` 事件。
- 跨模块影响：`result.impacts`。
- 不完整运行：`artifacts/disclosure_checkpoint.json`，含已提交专题、影响、计算、已读页及未完成状态；部分结果不代表本次分析完整。
- 完整返回结构和字段映射：`展示与合并交接.md`。

每次任务的文件名和 SHA-256 进入本地清单；不得提交年报 PDF、配置文件或运行数据。独立工作台接入仅限 V3.6.2 本任务副本。后续合并到总基底时，仍须由集成任务审核公共注册、页面组件和数据库字段，不应直接把此工作区视为六模块合并版。
