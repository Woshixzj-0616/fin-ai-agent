## 原文复核

- 对照 PDF 提取文本，营业收入、归母净利润、经营现金流、利润总额、净资产收益率等关键数值及报告页码与原文一致。
- V2.0 的 12 项指标中，10 项摘录被程序逐字匹配；经营现金流与归母净资产两项摘录被标记为“待核对”。人工查看 PDF 第 6 页提取文本后，数值和同比均与表格相符，但模型摘录压缩了表格中间的比较列，因此未通过逐字校验。界面保留警示和来源页，不把这两条标成已验证原文。
- 同报告追问联调使用比亚迪 2025 年年度报告（268 页）。首轮读 20 页；追问新补读第 219、220 页，回答引用第 40、130、219 页，并区分了年报披露原因与数据推断。第 40 页原文说明经营现金流下降主要因购买商品、接受劳务支付的现金增加；第 130 页现金流量表数值与回答一致。
- 比亚迪首轮 Token 为 46,752 输入 / 5,439 输出；完成追问后累计为 68,954 输入 / 6,665 输出。

## 结论与范围

V2.0 在相同年报上保留了 V1.0 的关键数值，并能检索首批页面以外的原文、展示匹配状态以及围绕当前文件追问。一次同报告对照不能证明模型对其他公司、行业或 PDF 版式都可靠；扫描件仍不支持，财务判断仍需要查看原文和人工复核。
