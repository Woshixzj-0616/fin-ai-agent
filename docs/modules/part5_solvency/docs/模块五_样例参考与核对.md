### 应付债券列位与重分类核对

伊利 2024 年报物理第 197 页“应付债券”表格的 35.4135 亿元位于“期初余额”列；“期末余额”列为空。物理第 198 页债券变动表将 35.942 亿元列为“转入一年内到期”，页面说明也写明应付债券减少原因为转入一年内到期的应付债券。该项是列报重分类，不能推断为报告期内偿还完毕。新的结构化表格读取应保留空白单元格和列标题，并与相邻附注一起核对。

## 使用规则

1. 运行时只把这张表当作搜索线索；模型仍须读取年报原页并重新提交证据。
2. 先建立父项和组成项的 `included_fact_keys`，再调用债务合计或短债占比，避免把短期借款合计、票据贴现和组成明细重复相加。
3. `ocf` 只有在模型确认它是 2024 年期间现金流、并把 `measurement_basis` 设为 `period_flow` 或 `statement_cash_flow` 后，才可进入经营现金流/平均流动负债计算。
4. 任何“资金减受限部分”都要证明限制项目属于同一货币资金总额；无法证明时只报告账面货币资金和限制披露，不给出可用现金认证。

宁德时代、隆基绿能和美的集团暂作为迁移验证样本，不能把伊利的事实键、页码或重点直接套到它们。
