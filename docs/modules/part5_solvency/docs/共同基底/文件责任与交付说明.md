# V3.0.1 并行开发：文件责任与交付说明

## 共同基线

所有开发任务从 V3.0.1 的同一个基线提交开始。主版本目录为 `金融AI智能体_V3.0.1`；任务工作目录放在同级中文目录 `财报分析并行工作区`。每个任务只在自己的工作目录改动，避免同一份工作树上互相覆盖。

任务目录按中文命名：

| 任务 | 工作内容 | 主要负责文件 |
| --- | --- | --- |
| 00 共同基底 | 上下文、注册、记录、模型配置及集成问题 | `backend/core/`、`backend/module_registry.py`、公共说明 |
| 01 业务与经营背景 | 模块一专业分析 | `backend/modules/business/`、对应提示词和结果展示 |
| 02 盈利来源与变化 | 模块二专业分析 | `backend/modules/profit/`、对应提示词和结果展示 |
| 03 资产质量 | 资产结构、资产变动与资产质量分析 | `backend/modules/assets/`、对应提示词和结果展示 |
| 04 现金流 | 经营、投资、筹资现金流与利润现金含量分析 | `backend/modules/cashflow/`、对应提示词和结果展示 |
| 05 偿债能力 | 债务期限、融资成本、偿付能力与约束分析 | `backend/modules/solvency/`、对应提示词和结果展示 |
| 06 披露与风险 | 重要会计估计、审计意见、事项披露与风险线索 | `backend/modules/disclosure/`、对应提示词和结果展示 |
| 07 合并集成 | 组合运行、前序线索传递、跨模块冲突和整体结果 | `backend/modules/synthesis/`、集成层文件 |
| 08 前端呈现 | 让各模块的分析过程、结果和证据清楚可见 | `frontend/src/` |

目录名字是当前分工建议；如果开发中发现更合适的专业拆分，可以在提交时说明原因并调整。单个模块不应顺手改其他模块专业逻辑。

## 共同基底约定

模块入口的基本连接方式是 `run(context)`。上下文已经提供报告身份、候选页、原文读取与检索、模型调用、运行记录、程序计算记录、进度及前序模块结果等能力。模块可以按需要使用，不要求每个模块采用相同步骤、相同提示词、相同内部结构或相同专业字段。

模块交付时保留自己的分析内容，并给出可识别的模块 ID 和版本。结果应让使用者知道哪些是年报证据、哪些是计算、哪些是模型解释、哪些还待核对；具体呈现可因模块而异。模块可以增加自己的专用工具和结构，只要不覆盖其他任务文件并保留自己的运行入口。

需要修改共同基底时，先在任务交付说明中列出实际遇到的问题和建议接口，再由任务 00 集成；不要求模块作者把专业能力压缩进已有的共享字段。

## 合并顺序

1. 任务 00 提供可运行基线、接入示例、样本校验清单及本说明。
2. 任务 01—06 分别完成专业模块入口和真实结果，不直接改任务 00 文件。
3. 集成时先逐个接入已交付模块，保存各自分支/工作树中的原始提交，再将模块目录和注册项合入集成分支。
4. 任务 07 接入组合流程和跨模块关系；共享线索只作为待核查方向，专业模块仍以年报证据为准。
5. 任务 08 根据真实模块输出搭页面；不得只接通 API 却把模块结果隐藏或挤进一个笼统摘要。
6. 每轮集成后用同一组冻结年报检查上传、模块调用、结果展示、出处回查和运行记录，再形成下一个可用版本。

合并不是把八个人的文件夹机械复制到一起。集成时按提交记录和文件责任逐项接入，发现冲突时保留专业逻辑并明确接口调整，不以改写各模块为统一模板作为解决办法。

## 交付内容

每个模块提交：

- 模块 ID、模块版本、入口文件及其所调用的专业实现。
- 模块分析内容、使用的专用提示词/工具/计算和模块自己保留的输出字段。
- 运行结果示例及对应报告 SHA-256；注明真实模型调用还是确定性演示数据。
- 遗留错误、模型不确定项及本模块需要下游注意的线索。

不要提交 API Key、`.env`、上传年报 PDF、私有运行数据库或完整运行记录。交付时用本说明里的样本身份和 SHA-256 核验文件；PDF 在本机已有样本目录，其他电脑则按记录的来源库获取。

## 并行工作区的本机运行

任务工作区不会带入 `.env`、Python 虚拟环境、`node_modules`、上传文件或任务数据库。独立开发模块时可复用本机现有 Python 环境和主版本配置，例如：

```powershell
$Python = 'D:\ChatGPT项目\金融AI智能体\.venv\Scripts\python.exe'
& $Python -m backend.run_module --module profit --pdf 'D:\ChatGPT项目\金融AI智能体\data\raw\600887_伊利股份_2024年年度报告.pdf' --config 'D:\ChatGPT项目\金融AI智能体_V3.0.1\.env'
```

运行记录默认落在当前任务工作区自己的 `data/开发运行/`。要看完整网页产品时，从主版本目录启动 V3.0.1；并行工作区不各自启动同一个 8007 端口。
