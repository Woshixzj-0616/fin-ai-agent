## 研报核查：人工构造的混合真假主张

测试 PDF：`data/cases/模拟材料/人工构造_宁德时代_2024_混合主张.pdf`，与宁德时代 2024 年原年报配对。测试 PDF 明确标注为人工构造，**不是券商研报**。预先写定的逐条答案见 `data/cases/模拟材料/人工构造_宁德时代_2024_人工答案.md`。

修复后完整任务 `36a34103b6c0452688245693f5a04e46`：7 条主张全部完成，结果为 2 条“已核对一致”、3 条“发现错误”、1 条“证据不足”、1 条“超出范围”，与预写答案逐条一致，且无失败项。植入错误分别是营业收入同比方向、储能收入占比、客户/供应商占比混淆。预测被排除在历史事实核查之外。

修复前任务 `c41845cdcf1247ae9c62c0668dbecb5f` 曾把“境外收入下降完全由汇率造成”判为“发现错误”，仅凭年报没有这段因果解释就作确定判错，属于误报。随后增加规则：缺少直接因果依据、也没有直接反证时归为“证据不足”。单条复测任务 `531f6e47e6474e28b79bea2560bcdfd7` 和修复后完整任务均将其判为“证据不足”。旧任务保留原结果，供回看问题来源。

## 当前结论与下一轮工作

- 这批测试证明流程能处理两家公司年报，并能在一份人工构造样例中识别 3 种数值错误；样例数量不足以估计真实研报的检出率或误报率。
- 模块一需要支持“主营业务收入”自己的分项合计和占比，同时继续与合并报表“营业收入”分开；不得把两套数硬凑成一个占比。
- 对模型给出的摘要、不确定项和未通过逐字匹配的摘录，仍需逐项人工核对；目前程序校验不能证明模型选对了表格或理解了因果。
- 下一轮应准备未参与改规则的另一批年报与模拟错句，分别记录主张抽取覆盖率、判断正确率、误报、证据页码、单位/期间错误及 API 用量，再决定是否冻结模块一。
