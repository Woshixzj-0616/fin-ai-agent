# 模块二 V3.2.0 实施记录

更新日期：2026-10-04

## 版本边界

V3.2.0 是从 V3.1.2 基线复制出的独立工作副本，分支为 `version/v3.2.0-module2`，本机端口为 8005。V3.1.2 继续使用 8004；本版的服务、任务数据库、上传 PDF 和日志均位于本版目录。

## 已完成的接线

- 上传任务可选择“模块二：盈利来源与变化”；后端为 `profit` 任务调用独立分析流程并记录模块提示词版本。
- 复用已有全文 PDF 索引、页码回看、任务保存、结果记录和追问功能；模块二追问会重建本模块规则和已保存事实，不依赖旧模型对话记忆。
- 流程包含利润主题候选页定位、DeepSeek 提取、程序校验、定向补查、DeepSeek 解释和结果保存。补查实际使用年报全文搜索/读页工具，提取/解释失败会保留可用阶段信息。
- 结果页展示本期与上期利润事实、程序复算指标、归母利润变化桥、利润层次勾稽、分部毛利资料、非经常性损益、证据解释、覆盖状态和未解决问题。原文页码可点回 PDF。
- 启动入口为 `打开V3.2.0工作台.cmd` / `启动V3.2.0.ps1`，通过 8005 与 V3.1.2 区分。

## 确定性规则

- 金额使用 `Decimal` 转换成元后计算；原文值、单位和符号继续保留。
- 毛利率分母仅使用营业收入，不拿营业总收入替代。
- 费用/收益贡献乘以报表项目的加减角色，不按行名统一翻号。负数财务费用变化、已带负号的减值项目均按测试用例复核。
- 营业总收入与收入子项、营业总成本与成本子项只有在本期和上期都精确复现小计时才采用子项，否则使用年报小计并把子项保留为不纳入合计的明细。
- 利润桥只接收相同本期/上期年度、同一合并/母公司范围、同一币种且引用及金额通过核对的利润行。无法满足时显示差额或未计算原因。
- 勾稽包括营业利润已识别项目、利润总额、合并净利润、归母净利润，以及归母与扣非和报告明示归母非经常性损益净额。空白或未提取项目不被自动当成零。精度容差根据年报金额显示位数和单位计算。
- “会计贡献”只解释利润表加减变化，不自动成为经营因果结论。模型解释的出处由程序限定在已读取 PDF 页并逐字核对。
