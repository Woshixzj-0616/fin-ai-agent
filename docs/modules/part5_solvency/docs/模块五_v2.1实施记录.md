## 完成的改进

1. **核实 PDF 表格列位置**：PDF 提取结果现在保留空白表格单元格和单元格边界。遇到合并单元格导致金额与列标题索引错一格时，事实校验改用单元格横向重叠关系识别列，不再仅按数组下标判错。表格续页可引用相邻页表头；没有可验证位置时仍拒绝把事实用于计算。
2. **调整短期债务口径**：允许把报告日后一年内到期的合同期限分桶与同日、同范围的负债余额计算短期债务占比；超过一年或口径不匹配时拒绝计算。
3. **改进报告期选页**：期限附注的报告期和比较期页面并列命中时，优先提示读取本年报告期页面。
4. **完整展示可追溯结果**：报告专题可识别嵌套的事实和计算引用，自动附上对应计算结果；缺少引用或事实未确认的定量表述会进入待复核。比率以百分比展示，同时保留原始值；发现标题缺失时按主题补齐。
5. **改进调试留痕**：开发运行记录标记代码工作区是否有未提交改动，避免把 `400910e` 误认为运行时的完整代码版本。
