# P1 解析停判首批验收（2026-10-17）

> 分支：`p1-parse-disambiguation-20261017`（从 P0 `2c3f62a` 起）
> 范围：公司、期间、单位、归母/合并口径的可解释停判；不包含 P2 抽取泛化。

## 1. 交付内容

- 核查行新增兼容字段 `resolution`，保留既有 `reason_code`：
  - `status` / `label`：唯一解析、候选待定、材料未加载、多公司歧义、期间冲突、单位冲突、口径冲突。
  - `candidates`：代码、名称、原文匹配、是否已加载。
  - `conflicts`：字段、原文值、模型值、定位依据、原文片段。
  - `next_action`：加载材料、选择公司、确认期间/单位/口径或转人工。
- 原文公司优先于模型字段；发生冲突时保留模型字段痕迹。
- 多公司上下文不再允许模型字段静默指定主体；必须唯一解析或停判。
- 单位支持千元、百万元，并与万元、亿元、元按同一直接引文规则核对。
- Markdown 报告和工作台均展示解析状态、候选、冲突字段和下一步动作。
