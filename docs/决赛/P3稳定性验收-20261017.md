## 1. 首批范围

本批不发起真实模型调用，先建立可复现的离线故障矩阵和统一失败码：

- 请求超时。
- 429 限流及有限重试。
- 401/403 认证失败。
- 400/404/422 参数或模型名失败。
- 502/503/504 上游不可用。
- 无效 JSON 和错误协议。
- 流式响应截断。
- 请求内及跨分块模型身份变化。
- 运行预算耗尽。
- 工具执行异常。
- 分块部分成功、已完成结果保留和检查点续跑。
- 响应或检查点中的密钥安全。

## 2. 失败分类

新增稳定 `failure_code`，不把异常文本或服务端原文当结构化状态：

| 失败码 | 含义 |
| --- | --- |
| `auth_failed` | 认证或权限失败 |
| `invalid_request` | 请求参数、地址或模型名无效 |
| `rate_limited` | 限流 |
| `upstream_unavailable` | 上游服务不可用 |
| `redirect_rejected` | 重定向已拒绝，密钥未转发 |
| `timeout` | 请求超时或总时限耗尽 |
| `network_error` | 网络连接失败 |
| `response_truncated` | 响应中断或截断 |
| `invalid_response` | JSON 或字段协议无效 |
| `model_identity_changed` | 模型身份变化 |
| `budget_exhausted` | 运行预算耗尽 |
| `checkpoint_invalid` | 检查点缺失、被篡改或绑定不一致 |
| `secret_blocked` | 检测到敏感凭证 |
| `tool_failed` | 工具执行失败 |
| `cancelled` | 任务取消 |
| `unexpected_exception` | 未预期异常，显式转复核 |

`failed_chunks` 和失败行均携带 `failure_code`；汇总结果增加 `failure_codes` 计数。原有 `error_type`、`reason_code` 和中文原因保留。

## 4. 集成验收

- 401 发生后只请求第一个分块，后续分块不发请求；未完成句子全部保留 `auth_failed`。
- 超时进入 `failed_chunks`，不会被统计为合理弃答或正确。
- 分块部分失败时，已完成分块和同块已完成原子继续保留；检查点可续跑。
- 工具异常写入 `tool_failed`，不覆盖相邻已完成结果。
- 测试密钥未出现在运行输出、检查点或故障矩阵 JSON 中。
- 全量测试：`498 tests`，`OK (skipped=2)`，`31.730s`。

## 5. 原目标结账与边界

| 原目标 | 结论 |
| --- | --- |
| 失败可归类 | 首批达标：16 类稳定失败码，8 个离线必测场景 |
| 已完成结果可保留 | 达标：分块和同块已完成原子均保留 |
| 用户可理解状态 | 达标：错误码、中文原因、块状态和检查点同时保留 |
| 不把失败伪装成弃答或正确 | 达标：失败、超时、弃答、缺失分别计数 |
| 真实模型稳定性 | 未完成：本批未发起真实模型调用 |
| 真实服务商限流/超时 | 未覆盖：只用本地 MockTransport 注入 |
| 独立人工复核 | 缺失：无独立复核 |

边界必须保留：

- 离线矩阵证明故障路径可归类、可恢复、可安全落盘，不证明真实服务商当前网络质量或模型质量。
- 真实网络和长文档后续验收见 `P3真实长文档稳定性验收-20261017.md`；该批 3 轮完成，但未触发真实 429/超时。
- 本批不产生模型准确率，也不更新 P0 的 96.67% 真实模型结果。
- 取消、已有恢复边界和工具失败已由全量回归共同覆盖，但本表不把它们折算成模型准确率。
