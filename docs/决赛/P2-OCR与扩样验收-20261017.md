## 2. 实现口径

- 无文字层扫描件在未显式启用 OCR 时明确拒收，不返回空结果冒充成功。
- 显式启用 OCR 后，OCR 页面强制标记 `ocr_used=True`、`review_status="needs_review"`，并写入 `ocr_requires_manual_review`。
- 保存产生事实的原页 PNG 与图片指纹，同时记录语言、语言包指纹、页码和事件，支持人工回看。
- OCR 页面复用同一 `Page` 对象承载 `textpage`，避免 PyMuPDF 弱引用失效。
- 自动抽取和 OCR 通道分栏执行；OCR 数值诊断不计入自动准确率。

本批没有修改 Agent 的审计、停判或模型业务规则。
