## 二、报名与参赛条件（有几条是硬杠）

- **报名链接**：https://app.cufe.edu.cn/scenes/Aljc9u
- 面向北京市在校本科生，**可在京内跨校跨专业自由组队**
- 每队 **3~5 人**，需 1 名队长；**每人只能参加 1 支队伍**
- **队伍名单一经确认不能更改**，否则视为放弃资格 → 加人必须在报名前定
- 需要上传**校园卡或加盖学校公章的学生证照片**
- **每队必须配备指导老师 1 人**，每位老师最多指导 3 支队伍

---

## 三、提交要求（初赛 vs 决赛）

**初赛**：项目计划书（PDF）+ 项目介绍视频（MP4，≤5 分钟、≤500MB）

**决赛**：最终报告书 + 可运行的系统原型（Web 界面或命令行均可）+ 完整源代码及运行说明 +
**评审现场可实时处理的样例数据** + 现场展示和答辩。
源代码要包含任务编排、工具调用、提示指令、数据处理、日志记录等核心模块，并附依赖文件，

## 四、奖项与综素

- 特等奖 1 名、一等奖 3 名、二等奖 5 名、三等奖 10 名
- 奖金：特等 1 万元 / 一等 5000 / 二等 3000 / 三等 1000（现金或等值 token，以后续公告为准）
- **获奖队伍有推荐至金融机构实习的机会**
- 综素：经管学院 24 级及以后本科生代表北林参赛可获综合素质（智育）参与分，获奖加奖励分，
  认证为 **C 类竞赛**；**信息学院加分情况以本学院通知为准**（我们是信息学院，需单独确认）

## 五、对我们最要命的 6 条约束

1. **指导老师是硬性要求**，且每位老师最多带 3 队 → 要早找，晚了名额没了。
2. **报名 10/11 截止，名单确认后不能改** → 想加人（比如加一个经管的同学）必须在报名前决定。
   赛制**鼓励跨专业组队**，这正好是补齐我们"没有金融背景"短板的机会。
3. **10/18 是第一次交付**，要计划书 + 视频；视频要演示 → 原型不能是空壳。
4. **决赛要"评审现场可实时处理的样例数据"** → 评委可能带一份我们没见过的新数据现场跑。
   **抽取器必须通用，不能对固定几家公司硬编码。**（演示数据可以窄，架构不能窄）
5. **初赛不交代码**，但决赛要"与现场展示版本一致的完整源代码" → 建议从第一天就用 git 管，
   别到最后补。
6. **第三方数据要列明来源、许可证、使用范围** → 用年报、开源库都要登记。
