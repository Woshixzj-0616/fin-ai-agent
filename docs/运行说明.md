# 运行说明

命令均在 `fin-ai-agent/` 仓库根目录执行。Windows 可将 `python3` 换成已配置的 `python`；不要求特定绝对路径。

## 现场一键演示

```bash
python3 -B scripts/run_onsite_demo.py --mode both
```

启动器先检查入口、样例、PDF、许可证说明和三故障演练口径，再在隔离目录执行离线 CLI，最后启动 Web。默认地址为 http://127.0.0.1:8765/app/；端口占用时传 `--port 8875`。

```bash
python3 -B scripts/run_onsite_demo.py --mode check
python3 -B scripts/run_onsite_demo.py --mode cli --run-root work/onsite-demo-runtime
python3 -B scripts/run_onsite_demo.py --mode web --port 8875
```

`check` 只做离线自检，`cli` 跑样例分析，`web` 直接启动页面。默认 CLI 产物写入 `work/onsite-demo-runtime/results/`，不覆盖正式 `results/`；`--run-root` 也可直接传给 `agent/main.py`，位置在子命令之前。

## 环境与检查

Python 3.11+，PyMuPDF 1.28.2、httpx 0.28.1，依赖版本以 `requirements.txt` 为准；运行完整开发测试另需 Node.js 20.19+（前端测试使用内置测试器，无 npm 依赖）。原赛题修复使用 macOS、Python 3.14.5；2026-10-09 的后端升级另在 Windows、Python 3.12.14 上验证，详见 `results/backend_upgrade_report.md`。

```bash
python3 -m pip install -r requirements.txt
python3 -B -m unittest discover -s agent -p 'test*.py'
```

原赛题修复记录见 `results/competition_validation.json`，后端升级记录另列，不覆盖历史验收；缺少真实样例会明确 skip，可选 OCR 没有语言数据也会 skip。只运行旧 `agent/test.py` 不包含新增赛题与后端测试。

## 网页与现场材料

```bash
python3 -B agent/webui.py
```

打开 http://127.0.0.1:8765/app/ 。财务报告身份未识别时手填代码、简称和年度；比较材料须为同公司，最多四份。单份 PDF 最多 40MiB，全部 PDF 合计最多 80MiB。先上传茅台 2025 半年报，再添加 2025 一季报，可检查累计拆季：跨报告会计政策、合并范围或重述版本未知时，Q2 尝试值明确标为“未获可比性确认”，不能当成有效季度值或继续计算环比。每份报告的页图以指纹区分。

选择质押、中标或股权变动，可获得字段 JSON、缺失/冲突和页图。扫描公告需勾选 OCR，先运行：

```bash
python3 -B scripts/setup_ocr.py
```

该脚本以 HTTPS 下载固定的 tessdata_fast 4.1.0 中文/英文数据，核验 SHA-256，保存于被 Git 忽略的 `data/ocr/tessdata/`，不安装系统软件。也可指定 `TESSDATA_PREFIX`。财务扫描件仍应转成经复核的文字层报告。

新工作台的输入副本、页图、结果与日志位于 `results/runs/<run_id>/`，各运行独立保存，同一会话可在列表切换；该目录已加入 Git 忽略。旧兼容页面 `/` 的工作区仍为 `results/webui_work/`，CLI / 兼容页面按原方式归档。

完成后可下载 `result.json`、`report.md`、`explanation.json` 和 `reproduction.zip`。复现包包含执行时 `source_code.zip`、依赖与配置快照、原始输入、完整结果、文件指纹及日志；不导出用于访问本机会话的 Cookie / session_id。把源码解压到新目录，按本说明安装依赖，再按包内 `run/run.json` 的完整参数重新提交原始 PDF。模型凭证需自行提供；模型的云端权重版本和非确定输出不保证逐字相同。

“模型计划、工具与裁决依据”展示实际记录的结构化计划、工具参数与结果、公式操作数、证据页码、失败/回退和裁决规则。实时事件先展示预览，结果保存后提供完整业务步骤；长列表可以加载更早的事件，完整记录也可导出。未调用模型时明确标注。这里展示可核验的分析说明，不保存或展示模型私有思维字段。

指标表区分同比、较上年末变化和百分点差；ROE 本值为 `%`，EPS 为 `元/股`。披露值会区分原文未披露、未提取到和无法核对。打印按钮支持浏览器“另存为 PDF”，打印时展开报告全文并解除滚动区域高度限制。

## Skill 与 MCP

Skill 作业规程（流程 / 工具契约 / 主张 Schema）在 `skills/fin-report-audit/`，与代码契约由 `agent/test_skill_mcp.py` 防漂移。

MCP 服务（JSON-RPC 2.0 over stdio，MCP 子集 `initialize` / `tools/list` / `tools/call`）：

```bash
# 自检（无客户端）
python3 -B agent/mcp_server.py --facts results/evidence.json --self-test

# 作为 MCP server（stdin/stdout 为协议帧，日志走 stderr）
python3 -B agent/mcp_server.py --facts results/evidence.json
```

`tools/list` 直接读 `agent/tools.py` 的 `tool_specs()`，与 JSON 多步协议同一套 name/parameters。另有会话工具 `load_facts` / `session_info`。任一 MCP 客户端（如 Claude Desktop 的 `mcpServers` 配置 `command=python, args=["agent/mcp_server.py","--facts","results/evidence.json"]`）可调用本地证据裁决工具。

## LLM 配置

只在进程环境配置 `LLM_BASE_URL`、`LLM_MODEL`、`LLM_API_KEY`，或在命令中使用 `--ask-key` 隐藏输入临时密钥。地址须为服务商明确提供的 HTTPS Chat Completions Base URL。不要将凭证写入草稿、脚本或 Git。

```bash
python3 -B agent/main.py check-text --file 草稿.txt --ask-key
```

默认受限工具循环，协议错误可按预算修正或回退单次拆解；网络重试耗尽、认证和参数错误不会借协议回退重复发请求。`--no-loop` 可显式选择单次模式。输出模式默认 json_schema，不支持时由用户显式选 json_object。后端升级初期使用本地模拟接口；2026-10-12 已完成真实模型全链路实测，详见[全链路实测记录](全链路实测记录-20261012.md)。

**原项目 DeepSeek 实测配置（历史记录）**：`LLM_BASE_URL=https://api.deepseek.com/v1`、`LLM_MODEL=deepseek-chat`、**`LLM_FORMAT=json_object`**。当时 json_schema 返回 HTTP 400，工具循环可执行 `list_catalog`/`compare_claim`；`submit_claims` 字段不齐会按设计回退单次拆解（`loop_fallback` 留痕）。2026-10-12 已重测上述配置及流式响应：接口实际返回模型名 deepseek-flash，最终三次固定样例均 8/8 应判正确；模型名不证明权重固定，其他配置仍以实际接口为准。

HTTP 层（`agent/llm_http.py`）：httpx + 有限退避重试（429/502/503/504/网络超时，默认最多 3 次重试，即最多 4 次物理尝试）+ 可选 SSE 流式。`LLM_STREAM=1` 开启流式聚合（含 tool_calls 增量）；重试记入 `llm_retry`，物理尝试另行统计。响应总时限、整篇时限、工具次数与 Token 预算集中在 `agent/backend_config.json`。无 httpx 时退回 urllib（无流式）；两种路径均拒绝模型接口重定向。

语义检索（`agent/retrieval.py`）：年报页文本切块 + BM25（中文字符 n-gram）；可通过 `retrieval.set_embedding_hook` 注入向量模型。`search_text` 工具返回相关段落 page/snippet，**不能单独裁决数值**。

联调免全量重抽（复用已有证据）：

```bash
python3 -B agent/main.py check-text --file 草稿.txt --evidence results/evidence.json
```

长草稿自动按章节与整句分块，沿用 fin 每块最多 12000 字、40 句的限制，保留全文唯一句子编号。部分失败仍输出已完成结果和未完成句子编号；CLI 返回非零状态，网页沿用现有失败状态，并保留可读报告。使用相同输入、证据、代码、模型配置及运行配置恢复：

```bash
python3 -B agent/main.py check-text --file 草稿.txt --evidence results/evidence.json --resume
python3 -B agent/main.py check-text --file 草稿.txt --evidence results/evidence.json --config agent/backend_config.json
```

`FIN_AUDIT_CONFIG` 可为所有后端入口指定配置文件；`check-text --config` 优先于该环境变量。检查点平铺在 `results/text_checkpoint_*.json`。已完成分块复用，未完成分块重新执行；请求、工具和 Token 消耗跨恢复累计。耗尽预算后需调整配置开始新任务，不能靠反复恢复清零。具体默认值及边界见 [后端升级说明](后端升级说明.md)。
