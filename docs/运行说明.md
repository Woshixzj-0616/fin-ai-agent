# 运行说明（决赛 / 评审现场用）

> 目标：**换台电脑、按本文从零跑通**。命令均在仓库根目录执行（`fin-ai-agent/`）。
> 给人看的一律中文；命令行标识符保留英文。

---

## 0. 环境

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11 或 Linux / macOS |
| Python | **3.11+**（本机验证 3.14.6） |
| 依赖 | `pip install -r requirements.txt`（目前只有 `pymupdf`） |
| 磁盘 | 年报约 430MB（`data/raw/`，已有则不用重下） |
| 网络 | 仅「下载年报」与「LLM 拆句」需要；抽取/核查/评测可离线 |

```powershell
cd fin-ai-agent
pip install -r requirements.txt
python -m unittest discover -s agent   # 或：cd agent; python -B test.py
```

**预期**：65 项测试全绿（约 15 秒）。

## 1. 现场一键（拿到新 PDF / 新公司）

### 1.1 已登记材料（推荐演示路径）

```powershell
cd agent
python main.py live --code 600519 --year 2024
```

产出：

- `results/live_report.md` —— 分析报告 + 现场摘要
- `results/evidence.json` / `events.jsonl` / `run.json` —— 证据与审计留痕

### 1.2 评审带来全新 PDF

```powershell
cd agent
python main.py live --pdf "D:\样本\XX公司2025年年度报告.pdf" --code 600000 --name 某某 --year 2025
```

说明：

- 会校验 PDF 可读、公司名/代码能在文中定位；
- 文件指纹（SHA-256）入台账，**不覆盖**已有材料；
- 报告年度以 `--year` 为准。

### 1.3 打包审计台（表格 + 点击溯源）

```powershell
# 在仓库根
python scripts/site_build.py
```

浏览器打开 `docs/index.html`（或用 `python -m http.server` 起本地服务）。

## 3. 纠错核查（研报草稿）

```powershell
cd agent
python main.py check-text --file ..\data\eval\drafts\600519_2024_injected.txt
```

需要环境变量（或 `--base-url --model`）：

| 变量 | 含义 |
| --- | --- |
| `LLM_BASE_URL` | OpenAI 兼容 HTTPS 地址（不要带密钥/查询串） |
| `LLM_MODEL` | 模型名 |
| `LLM_API_KEY` | 密钥（也可用 `--ask-key` 临时输入，不落盘） |

**架构口径**：模型只把句子拆成 JSON；**对错判定与计算全部本地 Python**。

无密钥时仍可跑确定性部分：

```powershell
python scripts/eval/run_eval.py          # 错误注入评测（离线）
```

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 中文乱码 | 结果一律读 UTF-8 文件；PowerShell 可设 `PYTHONIOENCODING=utf-8` |
| `pymupdf` 安装失败 | 用官方 wheel：`pip install pymupdf==1.28.*` |
| 报「没有匹配的已登记材料」 | 先 `python main.py import-existing --source ..`，或用 `live --pdf` 现场登记 |
| 报「材料抽取不完整」 | 看 `results/failures.json`；多半是 PDF 无文字层（扫描版需 OCR，首版不支持） |
| LLM 超时 | 只影响拆句；确定性核查与评测不受影响 |

## 7. 评审现场 5 分钟清单（打印这一页）

| 分钟 | 动作 | 预期（屏幕上能指到） |
|---|---|---|
| 0:00 | `cd agent` → `python -B test.py` | **85 项测试全绿** |
| 0:40 | `python main.py live --code 600519 --year 2024` | `live_report.md` + 证据条数 |
| 1:30 | （若有新材料）`python main.py live --pdf 新.pdf --code … --name … --year …` | 「已登记现场材料」 |
| 2:20 | 仓库根 `python scripts/live_drill.py` | 多公司演练表 `results/live_drill.md` |
| 3:20 | `python scripts/tool_demo.py` | **工具调用链** 5 步（`compare_claim` 出对错） |
| 3:50 | `python scripts/eval/run_report_eval.py` | 研报文体 **18/18** |
| 4:10 | 打开 `docs/index.html`（或 Pages）点一行证据 | PDF 页上高亮数值 |
| 4:40 | （可选）`check-text` 一份草稿 | 双轨报告 A/B/C |

**断网/无密钥**：跳过 `check-text`，其余全部离线可跑。  
**扫描版 PDF**：会得到人话拒收（见 §6），不是空白报告。

## 8. 五分钟答辩口径（备用）

1. **问题**：研报数字错误常见，人工校对慢，大模型会编数。
2. **做法**：年报抽数字 → 本地 Decimal 计算 → 对草稿逐条挑错；**LLM 判语义，代码锁证据**。
3. **铁律**：模型不裁决；每个数字带页码 + 坐标 + 哈希；预测只标记。
4. **证据**：70 份年报；错误注入 P/R=100%（受控扰动口径）；研报文体 18/18；E5c 端到端 12/12。
5. **现场**：`live` / `live_drill` 处理新材料，审计台可点回原文。
