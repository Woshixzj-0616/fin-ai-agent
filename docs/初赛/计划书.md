# 金融投研智能体 · 项目计划书

2026 北京市大学生金融人工智能竞赛。方向：1 数据结构化提取 + 2 上市公司财务报告分析 + 5 研究报告纠错核查。日期：2026-10-07。

队伍信息沿用协作仓库记录：北京林业大学信息学院、3 人；成员、指导教师和报名信息由团队核实后填写。本稿对应可运行原型，不将未人工完成的事项称为已验收。

## 项目目标

从原始公告、财务报告提取可定位字段，对研报草稿进行结构化拆解、确定性核查及可执行修正。交付 JSON、表格、报告、页图和执行轨迹，每项结论可追溯至文件指纹、原页位置及计算规则。

## 三个方向的具体落点

| 方向 | 输入与处理 | 输出和边界 |
|---|---|---|
| 1 公告结构化 | 质押、中标、股权变动；标签、表格、限定中标正文；可选扫描 OCR | 三类事件 schema；原值/规范值、必填缺失、正文/表格冲突、页码位置；OCR 字段需复核 |
| 2 财务分析 | 年报、半年报、季报；同期间同比；累计流量拆单季后环比 | 非经常性差额占比、扣非同比、利润现金流背离幅度/连续性、历史列示变化线索；缺明细时给原因补证框架 |
| 5 研报纠错 | LLM 拆句和受限工具请求；代码核查收入、利润、单位、口径、倍数、引用 | 判定、修改片段、公式及证据；倍数明确内部一致性范围；引用区分页码体系与支持范围 |

财务指标抽取属于方向 2 的支撑链路。方向 1 交付公告事件字段，不把年报指标冒充公告事件。

## 技术架构

材料登记 → 年报 / 期间报告 / 公告解析 → 结构化证据 → Decimal 计算 → LLM 拆句和受限工具循环 → 本地门控与裁决 → 网页、报告及完整运行归档。

单次拆句不提供标准答案；工具循环可请求查询证据或比较，裁决始终来自本地规则。事实为原始字段及可复算结果，推论为待补证据的分析框架，模型解释标为未完全核实，不输出投资观点。

轨迹展示实际模型输入输出 JSON、通道、去重规则、工具参数、公式、操作数和门控，不生成私有思维链。webui 与 docs 共用轨迹组件。

## 当前材料与验证

保留仓库历史 70 份年报底板及旧评测。本轮回归固定九份年报，并加入茅台 2025 一季报及半年报、复星质押公告和隧唐科技中标公告；三类模拟公告与模拟扫描件明确标注。

最新结果见 results/competition_validation.json 和 docs/赛题修复验收.md。固定值回归、合成边界测试、历史错误注入、人工盲测分别说明。受控注入的 P/R=100% 不代表任意研报、公告或 OCR 的独立准确率；24 条参考答案仍需团队人工复签。

## 交付与复现

Python 3.11+，PyMuPDF 1.28.2。提供依赖、全部源码、运行说明、第三方清单。上传页面支持新公司财务报告和三类公告；CLI 可复跑，静态页面展示预跑快照，部署版本以实际提交核对。

每次运行保存环境、模型身份、文件访问、输出和源码指纹；工具及计算在 events.jsonl，可读步骤在 trace.json，历史和当时源码在 history.zip。OCR 语言包固定版本和指纹，缺依赖时明确失败。

## 边界及后续

| 事项 | 状态 / 下一步 |
|---|---|
| 扫描 | 模拟扫描公告已验证，OCR 全部转复核；扫描财务和任意低清复杂表尚未承诺覆盖 |
| 期间 | 真实半年报和一季报已验证；缺基期不补猜；EPS、ROE、余额不拆差 |
| 估值 | 显式价格/企业价值输入，未独立核实行情；TTM、预测、非正分母转复核 |
| 引用 | 页序、印刷标签、字段/片段支持性；文本未命中不自动认定伪造 |
| 独立评测 | 团队完成复签、未参与开发人员盲测和基线对照 |
| LLM | 本轮无真实凭证，保留原接口及模拟协议回归；提交前实际联通并记录模型身份 |
| 许可 | 依赖许可集中核对；原 PDF 再分发、服务协议、整体源码许可需权利人核实 |

团队按正式通知确认名单、指导教师及提交节点，完成计划书和视频，再扩大未见公司、版式和真实扫描公告验证。赛程见 docs/赛程与关键节点.md。
