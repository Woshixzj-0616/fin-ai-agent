## 录制清单（建议顺序）

1. **先录屏幕**（约 6 分钟原始素材，剪到 2 分 50 秒）
   - [ ] 审计台四栏浏览（台账 / 证据溯源点击高亮 / 陈述核查 / 审计日志）
   - [ ] 终端：`python agent/main.py demo`
   - [ ] 终端：`python scripts/eval/run_eval.py`（拍到 P/R 打印）
2. **做 5 张标题卡**（PPT / Canva 均可，风格统一）
   - 标题 / 错误示例 / 架构图 / 评测结果 / 结束
3. **配音或字幕**：按上表旁白；语速约 220 字/分钟
4. **剪辑**：屏幕 60% + 标题卡 40%；总长 **4:30–4:50**
5. **导出**：H.264 MP4，1080p，≤500MB

## 演示脚本注意

- 命令输出保持中文；提前跑通，录制时**不要临时 debug**
- 审计台若线上打开慢，可本地 `python -m http.server` 打开 `docs/`
- 评测那句旁白必须和屏幕上打出的数字一致
- 视频里不出现 API 密钥、内网 IP、个人路径
