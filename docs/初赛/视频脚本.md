## 录制操作

在仓库根目录运行 `python3 -B agent/webui.py`，浏览 `http://127.0.0.1:8765/`。静态演示先按 `docs/运行说明.md` 构建，然后运行 `python3 -m http.server 8766 --directory docs`。线上版本要实际同步部署后再用于录屏。

测试命令：`python3 -B -m unittest discover -s agent -p 'test*.py'`。不要将受控错误注入、开发回归和团队人工盲测混成一个准确率。

- 录屏不展示 API 密钥和个人路径。
- 三类模拟公告、扫描样例、假设行情必须保留画面标签。
- 真实模型调用镜头仅在确实接入并留下模型名、参数及日志后录制；当前没有凭证，不录制伪造调用。
- 原 PDF 再分发权利、协作源码许可证及报名资料由团队确认，公开视频不声称这些手续已完成。
