# 版本记录

## V1.0：财报概览原型

- 保存日期：2026-09-28
- 核心流程：上传一份 PDF 年报，提取候选页，调用 DeepSeek 生成结构化财务概览，并在本机网页显示关键数据、分析和不确定项。
- 实际联调：长江电力 2025 年年度报告，PDF 共 259 页，程序选择 12 页，DeepSeek 请求完成，结果显示在工作台。
- 当前边界：阶段一概览只基于提交给模型的页面；金额仍按原始元数值显示，窄屏卡片换行较差；数值与出处尚未经过完整人工核对。
- 本地数据：真实 API Key、上传任务数据库和上传 PDF 均留在本机并由 `.gitignore` 排除，不纳入版本记录。
- 保存方式：Git 本地提交及 `v1.0` 标签；不自动推送到远程仓库。
