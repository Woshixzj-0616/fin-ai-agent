原型采用自定义 JSON 工具循环：Tools 在 agent/tools.py，Prompt/Schema 在 llm_check.py，调度在 agent_loop.py。Skill 定义在 skills/fin-report-audit/（流程、工具契约、主张 Schema，纯项目内文档）；MCP 服务在 agent/mcp_server.py（JSON-RPC 2.0 / stdio 子集，**自实现、无第三方 MCP SDK 依赖**，`tools/list` 与 `tools.tool_specs` 同源）。两者均为参赛原型运行时可接入的接口，不是空造占位文件。开发辅助工具不属于参赛原型运行依赖。

密钥从环境或隐藏输入读取，不保存于归档。模型名、主机、格式、工具记录和 token 用量随实际运行保存。云端权重可能更新，确定性计算可重跑，不承诺模型拆句逐字相同。

许可状态集中区分“已确认依赖许可”“公开披露再分发未核实”“上传权利未核实”“服务协议未核实”。清单不能替代权利人授权，也不能把人工复签改成程序签字。
