## 实际改动与原因

- **来源可追溯与获取控制：** 本地导入不伪造官方公告号或披露日期，获取时间单列。抽取证据携带来源，来源变更使缓存失效。检索候选、选择依据、异常公告字段、每次 HTTP 尝试可追查；有限重试、退避、重定向校验、解压及大小和时间限制防止无界获取。`latest` 只表示检索范围内最新候选，不能冒充最新有效版本确认。
- **待复核证据限制贯穿入口：** 新增质量标记映射到 fin 的 issues，数值核查、分析、问答、估值与 MCP 保持一致。问答概览不把待复核金额显示为可靠数值，问题列表兼容仅带扩展标记的证据。已知口径冲突拒绝比较，时点数及未定义流量不能累计相减；旧证据按 fin 原规则处理。
- **长文、预算与失败恢复：** 集中配置，按章节和整句分块，全文唯一句子编号与位置；无静默截断。成功分块保留，失败分块可恢复；部分完成返回非成功状态，报告列明未完成范围。物理请求、工具、Token 跨恢复累计，未知用量保留预占。服务实际返回模型名及名称变化记录，未声称模型权重固定。

新增 `agent/backend_runtime.py`、`agent/backend_config.json`、`agent/test_backend.py`；使用说明为 [后端升级说明](../docs/后端升级说明.md)。其余修改落在已有后端模块及 Markdown 文档，未新增持久目录。原测试文件未修改。
