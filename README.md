# 金融投研智能体 · 2026 北京市大学生金融人工智能竞赛

参赛方向：1 数据结构化提取 + 2 上市公司财务报告分析 + 5 研究报告纠错核查。源码基于协作仓库现有成果扩展，修复范围和验证记录见 [赛题修复验收](docs/赛题修复验收.md)。

系统从原始 PDF 提取带页码、位置和文件指纹的字段，使用 LLM 拆解草稿及调用受限工具，再由 Python / Decimal 复算数值并核查。输出包括结构化 JSON、报告、证据页图和可展开执行轨迹。

## 本轮实现

| 方向 | 实现与边界 |
|---|---|
| 1 | 质押、中标、股权变动字段 schema；标签、表格及限定中标正文句式；必填缺失和正文/表格冲突显式报告。可选扫描公告 OCR，所有识别字段需复核。 |
| 2 | 年报、半年报、季报身份与精确期间；同期间同比；累计流量拆单季后环比；非经常性差额占比、扣非增速、利润现金流背离幅度及连续性、历史列示值变化线索。 |
| 5 | 保留收入/利润/单位/口径核查；新增 PE、PB、明确输入的 EV/EBITDA 内部一致性核查；PDF 页序、印刷页标签和页内支持性核查；输出修改前后片段。 |
| 留痕 | 两套网页共用轨迹组件；记录真实抽取、去重、公式、模型拆句 JSON、门控、工具参数及结果；归档全部核心 Python 模块、脚本和界面源码指纹。 |

事实、推论和模型判断分别标明。原因分析在缺少毛利、费用、回款等明细时给出补证框架，不生成未经证实的因果结论。

## 运行

在仓库根目录执行。Python 3.11+，依赖锁定 PyMuPDF 1.28.2；本轮实测环境见验收记录。

```bash
python3 -m pip install -r requirements.txt
python3 -B -m unittest discover -s agent -p 'test*.py'
python3 -B agent/webui.py
```

打开 http://127.0.0.1:8765/ 。选择财务分析或三类公告；半年报可同时上传同公司的季报作为比较材料。网页上传不进入正式材料台账。

```bash
python3 -B scripts/setup_ocr.py
python3 -B agent/main.py announcement --pdf data/demo/real/fosun_2025_pledge.pdf --type pledge
python3 -B agent/main.py announcement --pdf data/demo/模拟扫描中标公告.pdf --type winning_bid --ocr
python3 -B agent/main.py audit --claims data/demo/audit_claims.json
```

更多入口、模型配置及静态快照构建见 [运行说明](docs/运行说明.md)。运行结果位于 `results/`，历史在 `history.zip` 中按完整运行归档。

## 数据与评测口径

仓库保留历史 70 份年报底板及旧评测记录。本轮实际回归为固定九份年报，另加入两份真实期间报告、两份真实公告，以及明确标注的模拟公告与扫描样例。未把旧的 70/70 或 P/R=100% 当作本轮全量重测结果。

错误注入使用抽取证据派生标签，只说明受控条件下的确定性核查能力；不代表独立盲测、任意研报准确率或 OCR 准确率。24 条固定参考答案的团队人工复签仍需真实人员完成。
