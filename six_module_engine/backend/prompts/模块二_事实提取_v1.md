# 模块二事实提取阶段

本阶段只提取和核对来源事实，不写业绩评价、经营因果、行业判断或投资建议。输出必须是单个 JSON 对象，不要 Markdown 代码围栏或对象以外文字。

```json
{
  "company": "公司名称",
  "period": "本期报告年度",
  "reporting_scope": "合并/母公司/不确定",
  "currency": "人民币/其他币种/不确定",
  "profit_lines": [
    {
      "profit_role": "上述受支持角色之一；不能确认时留空",
      "label": "年报项目原名",
      "current_value": "原始本期金额字符串",
      "current_unit": "元/千元/万元/亿元",
      "previous_value": "原始上期比较金额字符串；没有则空字符串",
      "previous_unit": "原始单位",
      "current_period": "例如 2024 年度",
      "previous_period": "例如 2023 年度",
      "current_scope": "合并/母公司/不确定",
      "previous_scope": "合并/母公司/不确定",
      "current_currency": "人民币或报告币种",
      "previous_currency": "人民币或报告币种",
      "source_pages": [91],
      "evidence_quote": "含有项目名、金额和期间的年报原文短摘录",
      "comparability_note": "是否重述、范围变化、不可比等说明"
    }
  ],
  "business_segments": [],
  "nonrecurring_items": [],
  "uncertainties": []
}
```

把报告确实列示的利润表项目逐项提取，并补查主表续页及重要附注。对于每个项目，优先提供同一张表的本期和上期比较金额。不能从金额推测缺失项。原文中的负号、括号负数、损失负值均须原样保留。

必须区分营业总收入小计、营业收入、利息收入和其他收入；必须区分营业总成本小计及其费用子项。不要复制同一数字来填充未披露期间，也不要因引用页面不在已读取清单而伪造一个页码。分部名称放在 `label` 中；非经常性损益角色必须由报告附表明确支持。

`profit_lines` 保存利润表和损益附注中用于利润形成、两期变化及勾稽的项目；`business_segments` 保存披露的分业务收入、成本或毛利率；`nonrecurring_items` 保存非经常性损益表的项目、税影响、少数股东影响和合计。确实没有时返回空数组。
