## 专业结果

结果外层遵守 V3.0.1 的工作流字典。`result` 包含五个模块专属板块、公司专属专题、被引用事实及计算、限制和待追问事项。板块 `key` 为：

- `cash_overview`
- `profit_to_cash`
- `operating_cash`
- `investment_cash`
- `financing_cash`

每个板块独立提供标题、状态、摘要、完整详情、相关事实编号、计算编号、PDF 物理页码和可选表格。额外专题不受五板块结构限制。

提交时必须恰好包含五个不同核心 key，各一次；最终结果固定按上述顺序输出，避免模型重复板块或把内容挤进一个模块。计算引用的原始事实及其出处会一并保留。

模型提交的财务内容与程序检查结果分别保存。原文数字出现、摘录匹配、行列/年度/合并范围身份不是同一状态；当前程序不自动认定行列身份。

提交入口会复核摘要、详情和总评中使用“元/万元/亿元/亿”等单位的阿拉伯数字，要求金额可从该处引用的人民币事实或程序计算中按显示精度换算出来。对不上时拒绝提交并把不匹配金额反馈给模型修订。此检查仍是数值对应检查，不证明该金额对应的财务科目、期间和表格列语义正确。

事实证据页会在模型回读或登记时实际加载，再核对页码、摘录和数字。计算要求单位、报告范围、期间区间和期间/时点类型一致；现金余额勾稽仅接受期末时点余额、期初时点余额与年度现金变动，并检查它们是否对应。证据身份仍待人工或更强表格结构识别复核时，结果保留醒目的 review flag。

最终提交前，如果经营净现金和长期资产购建现金支出存在唯一、同期间、同范围、同人民币单位的事实，程序会自动执行 `operating_after_capex` 并交给板块引用；歧义或证据不足时不自动计算。校验失败会逐项返回无效编号和行名证据问题，供模型修订或移除结论。该自动计算只代表经营现金减购建支出的模块观察值，不等同于自由现金流。

## 当前实现边界

- 仅处理可提取文字的年报 PDF；扫描件沿用基底错误提示。
- 安全金额换算当前支持人民币元、千元、万元、亿元；其它币种和未知单位保留来源，不参与金额计算。
- 不在本工作树修改共享注册表、上传接口、主页面/导出或公共计算器。
- 中途达到模型工具轮次上限时返回五个明确标记未完成的部分状态，且保留已收集事实和计算；底层模型连接异常由调用方记录失败。
- 同比只在连续两年且期间区间/时点类型对应时计算；跨范围、时点余额和期间流量不能混加。收支净额缺少任一方向时停算，不把缺项默认成零。
- `yoy_bridge` 按本期/上期成对输入净利润、全部带符号调节行和经营净现金，给出各项同比变化贡献及勾稽差额；缺少比较期行或分项不能解释总额变化时，不得宣称为完整归因。
- 本文件记录开发约定，不表示模型结论已通过真实年报核验。真实样例运行和另一家公司迁移记录在交付阶段补入。
