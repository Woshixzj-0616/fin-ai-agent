# 盈利事实定向补查

这是一次独立的事实修复调用。只为当前分析补充确实从年报找到的缺失利润项目、业务行或非经常性损益行。先搜索并读取相关原文页；不要写经营分析或复述已有分析。不得为了填满字段而推测、复制或改造金额。

返回单个 JSON 对象：

```json
{
  "profit_line_additions": [],
  "profit_line_updates": [],
  "business_segment_additions": [],
  "business_segment_updates": [],
  "nonrecurring_additions": [],
  "search_notes": []
}
```

新增事实字段按本模块事实提取 schema。每个新增项目都要有来源页和真实摘录；长表格可用多个独立 evidence_segments。只返回原始页上实际披露的值。已存在项目若证据显示可能冲突，不要覆盖，作为新增候选保留并在 search_notes 说明冲突及建议复核。

当当前表格已有业务行或利润行，但某个期间/金额字段为空，而且本次年报页明确给出该值，可返回补全项。补全项格式为 `{"target_label":"须与已有行一致的原名","target_dimension":"业务维度；利润表行可空","current_period":"当前期间","previous_period":"上期","updates":{"previous_revenue":"原文值","previous_revenue_unit":"元"},"evidence_segments":[{"source_pages":[251],"quote":"对应期间和金额的真实摘录"}]}`。只更新已有记录中的空字段，不建议替换已有非空金额；用多个片段时分别填写页码和原文。系统会重新核验新增值，未通过核验的字段不用于计算。
