# 模块三事实抽取阶段

从本次报告识别公司名称、证券代码（如实际披露）、会计期间、报告版本、合并或母公司范围、金额单位和币种。不要从文件名推断报告内容。

从给定页和后续查阅页抽取用于资产质量及效率分析的原始事实。除了资产负债表，还可提取利润表相关期间数、项目说明、减值、账龄、转固及其他附注。

每个事实仅代表一个科目/分类、一个期间或一个时点。`metric_key` 优先使用：`total_assets`、`current_assets`、`noncurrent_assets`、`cash_and_equivalents`、`accounts_receivable`、`notes_receivable`、`receivables_financing`、`contract_assets`、`other_receivables`、`prepayments`、`inventory`、`inventory_component`、`fixed_assets`、`construction_in_progress`、`goodwill`、`intangible_assets`、`right_of_use_assets`、`investment_property`、`long_term_equity_investment`、`other_asset`、`operating_revenue`、`operating_cost`、`asset_impairment_loss`、`credit_impairment_loss` 或 `other`。无合适项时用 `other` 并保留报告原名。

事实结构：

```json
{
  "metric_key": "accounts_receivable",
  "original_label": "应收账款",
  "dimension": "",
  "value": "123.45",
  "unit": "万元",
  "currency": "CNY",
  "period_type": "instant",
  "period_label": "2024年末",
  "period_start": "",
  "period_end": "2024-12-31",
  "as_of_date": "2024-12-31",
  "reporting_scope": "合并",
  "measurement_basis": "gross",
  "adjustment_basis": "年报披露口径",
  "evidence": [
    {"page": 42, "role": "label", "quote": "报告中实际出现的科目行"},
    {"page": 42, "role": "value", "quote": "包含所抽数字的原文"},
    {"page": 42, "role": "unit", "quote": "表格实际披露的金额单位"},
    {"page": 42, "role": "period", "quote": "表格实际披露的日期或期末列"},
    {"page": 42, "role": "scope", "quote": "合并资产负债表标题或母公司口径说明"}
  ],
  "note": "只写与识别/口径有关的简短说明"
}
```

字段约定：`period_type` 用 `instant`（时点）或 `flow`（期间数）。期间数填写准确起止日，资产负债表行填写时点日期。`measurement_basis` 用 `gross`、`allowance`、`net`、`carrying_value`、`cost`、`impairment`、`amount` 或 `unknown`。准备、净额和总额分开记录，不能把本期损益当成准备余额。

每条原始证据摘录需来自已读的 PDF 物理页，不能改写成自己概括的句子。`role` 只能使用 `label`、`value`、`unit`、`currency`、`period`、`scope`。科目和值的摘录必须能在同一行或相邻原文中对应；不要只引用孤立的“合计”或一串数字。若原文没有足够信息确认某个事实，就不要提交该事实。不要用“未提取到”填成零，不要把并排数字擅自猜成当前期/上期。准备、净额和总额等行身份需由科目证据支持。

为了让程序准确换算，按原文给证据标注 `role`；表格标题、日期列、单位和合并/母公司范围常在行的上下文中，摘录应包含相应标题或表头。`unit` 要区分元/千元/万元/亿元；`currency` 要确认人民币/CNY/RMB（或其他币种）；`period` 要能确认具体数值对应的日期/期间；`scope` 要确认合并或母公司口径。不要把摘录角色写成自由描述或科目名称。若原文无法确认某项口径，省略该事实或说明缺项，不要猜。

控制输出长度：最多提交 45 条最能支撑资产结构、应收、存货、长期资产和效率判断的事实；每条摘录尽量短，但必须保留足以核对科目、数值和表头的上下文。不要重复同一事实，也不要输出长段解释；缺少的细节留给后续按页查阅。

除事实外，用 `company`、`security_code`、`report_year`、`period_start`、`period_end`、`reporting_scope`、`currency`、`unit_context` 提供已核实的报告身份；无法确认的字段为空。用 `extraction_notes` 记录重要缺项、口径不确定或继续查找方向。

最终回答为 JSON 对象：`{"metadata":{},"facts":[],"extraction_notes":[]}`。报告没有披露或现有材料不清楚时保留空数组并说明，不能补造内容。
