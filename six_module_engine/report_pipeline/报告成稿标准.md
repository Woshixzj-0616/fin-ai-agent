# FinScope 财报分析报告：成稿标准与内容样例

制定日期：2026-10-15。用于纠正当前综合研报的内容目标和阅读方式。本文件是开发依据及局部写作样例，不是已完成的五粮液全篇分析报告。

## 1. 最终要交付什么

交付一篇能独立阅读的企业经营与财务分析报告。读者不需要了解六模块、发现卡、Agent、运行状态或生成过程，就能理解：企业怎样赚钱，本期变化来自哪里，增长与盈利的质量如何，利润如何转成现金，资产和资金承担什么压力，哪些变化最值得继续跟踪。

正文应形成一条完整的解释链：经营活动 → 收入与利润 → 营运资本与现金 → 资产负债与资本配置 → 综合判断。六模块是专业材料的来源，章节围绕公司真正的重要问题组织，既有跨领域主线，也保持基本财务覆盖。

先完成可以脱离工作台阅读的报告，再把报告放入工作台。接口返回成功、字段齐全、主题数量、字数与页码存在，都不能证明分析合格。

## 2. 当前成品的具体问题

- 第一屏突出运行号、API 调用记录、模块数量，缺少公司层面的结论和关键财务变化。
- 主题、反方复核和发现索引占据主阅读路径，正文在底部嵌套滚动框中以 Markdown 源码出现。
- 正文重复数字和限制，缺少增量贡献、利润变化桥、利润与现金勾稽等可以实际开展的分析。
- 反方复核主要追加否定句，未充分推动取证、计算和观点修订。
- 将模块提取失败带来的缺口直接交给读者，未先回查本地财报。系统未提取成功不等于公司未披露，更不等于企业财务风险。

## 3. 报告应怎样展开

### 第一页：核心判断和财务快照

标题明确公司、年度、合并或母公司口径。先给一段公司层面的综合判断，再给三到四条最重要的结论，每条包括关键数字、经济含义和影响判断的条件。只选真正重要的问题，不为凑数量制造观点。

财务快照列本期、可比上期、变动及简短解释。优先收入、毛利率、营业利润或归母净利润、经营现金流、资本开支、可用资金与债务等。指标按公司和行业选择，不强行填满空表。历史窗口按实际资料展开，无法取得的数据如实说明。

### 正文：围绕核心问题论证

1. 经营与增长来源：商业模式、主业结构、产品/地区/渠道的增长贡献，适用时拆量、价、组合。说明数据支持的经营变化及其持续性条件。
2. 盈利形成与质量：从收入、成本、费用、税费到利润形成变化桥，识别一次性项目、财务收益和会计口径影响。把结构影响与业务自身盈利变化区分开。
3. 利润与现金转化：将净利润桥接到经营现金流，追踪应收、存货、应付和合同负债；解释资本开支后的现金余量和资金用途。分子分母必须保持合并/母公司及期间口径一致。
4. 资产负债与资金安排：具体分析重要科目、资产效率、受限资金、债务期限与偿付资源、资本投入和分红安排，解释其与经营主线的关系。
5. 影响整体判断的特殊事项：审计、关联交易、会计变化、或有事项按重要性纳入相关论证；有必要时单列专题。
6. 综合收束与跟踪：回答最初提出的问题，给出有证据的总体评价；列少数能够改变判断的观察变量，说明看什么、为何看、何种变化支持或削弱当前解释。

上述是覆盖要求，实际章节可以合并、调整和改写为有判断的标题。重点专题允许同时使用多个模块；稳定且影响较小的事项简写。资料充分时正文约四千至八千字可作为编辑参考，不以长度判定合格。

## 4. 分析段落的最低质量

每个重要判断应自然完成：发生了什么 → 相对什么基准 → 贡献或机制是什么 → 对财务质量意味着什么 → 哪种相反证据会改变判断。

不能只把同比数字换成形容词。能够计算的贡献、差额和桥接先计算；需要判断的驱动说明证据；尚不能确定的原因说明候选解释以及区分它们的具体资料。

事实、管理层解释、计算和分析判断明确区分。反方论证应改变正文结论或推动补查；不逐段贴模板化的“无法判断”。关键限制紧邻相关判断，重复的运行说明收到底稿。

重要财报原始资料本地已存在时，优先回查表格与附注，修补关键证据。确实无法解决的重大缺口，限制受影响的结论，并准确标明报告尚未完整完成的部分。企业未披露、系统未提取、口径冲突三者必须分开。

## 5. 用本次五粮液材料说明“分析”应达到的程度

以下局部示例已回查本地《宜宾五粮液股份有限公司2023年度报告全文》PDF 第14–15页；计算采用该表披露的未四舍五入金额。没有完成三表和附注全量核验，因此不作为全篇最终结论。

### 收入增长主要由酒类贡献，区域扩张存在明显分化

2023年公司营业收入增加93.03亿元，其中酒类收入增加88.84亿元，贡献约95.5%的收入增量。酒类在总收入中的占比由91.34%升至91.80%，说明本期收入扩张主要来自核心酒类业务。

区域层面，西部与东部合计增加80.80亿元，占酒类收入净增量约90.9%；南部与北部合计减少10.11亿元，其余净增量来自中部。两个增长区域的重要性因此高于单看集团12.58%的收入增速所呈现的结果。后续渠道研究应分别解释西部、东部的增量来源及南部、北部的下降原因，再评价增长的广度与持续性。

计算依据：总收入增量=2023年收入−2022年收入；酒类增量贡献=酒类收入增量÷总收入增量；区域贡献为区域收入差额占酒类收入净增量的比例。各地区口径均为酒类收入。资料来源：原始年报第14页。

### 库存增加与产销差可以勾稽，备货效果需要后续销售验证

2023年披露的酒类生产量18.41万吨、销售量15.91万吨，两者相差24,994吨，恰好等于该产销存表的年末库存较年初增加量。该表的库存增加与生产超过销售的数量关系能够闭合。

年报将产量与库存增长解释为主要产品动销较好，并为元春旺季提前备货。该解释应作为管理层陈述呈现；数量勾稽只解释了库存怎样增加，尚不能确认备货能否顺利消化。分析的下一步是结合随后期间的销售与库存、存货构成及减值、收款和合同负债变化，检验备货是否实现预期。该表实物数量不直接等同于资产负债表存货金额，也不能直接替代渠道库存判断。

资料来源：原始年报第15页“公司实物销售收入是否大于劳务收入”及其原因说明。

这两段展示应有的取数、计算、解释与限定方式，不能用来替代整份公司的盈利、现金、资产与偿债分析。

## 7. 工作台应该如何呈现

进入综合报告，第一屏直接呈现报告标题、核心判断、关键财务快照和章节导航。正文连续阅读，使用正式标题、段落、原生表格及确有解释作用的图表。引用是可打开原文页的脚注或来源链接。

只有在图表能帮助解释趋势、结构或桥接时使用它。历史图不能以预测补历史；分产品组合不能凭合计数硬拆。阅读字号、列宽、单位和小数精度保持一致，支持打印和导出。

六模块原始结果、发现卡、反方论证过程和运行记录通过次级“分析底稿”入口查看。相关证据缺口仍在正文对应位置明示。上传区域和开发运行信息不抢占报告正文的主要阅读空间。

## 8. 分层完成，不把展示当研究完成

第一层先完成一份真实年报的合格成稿，用它明确内容目标。补齐主线所需的关键本地证据，形成主要计算表和论证，先解决“这篇报告本身是否成立”。

第二层把已经证明有效的内容要求写入发现提炼、统筹、复核和主编的职责与提示词，使它们能够产出同等质量的报告。主编从审查后的材料组织章节，不能只被要求列限制、附状态表。

第三层让工作台稳定呈现这份报告，并提供底稿回溯。后续再用其他企业检查方法能否迁移。

成稿验收看五件事：读者能否迅速获得总体判断；主要变化是否得到解释；三张报表是否相互联系；重要结论是否可追溯且计算口径正确；全文是否完成取舍并可独立阅读。关键财务支柱缺失时保留草稿身份，不能凭页面或接口正常将其称为完整合格报告。
