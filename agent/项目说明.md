# 证据字段、计算规则与边界

工程以原始 PDF 为证据，以结构化字段和确定性程序产生核查结果。方向 1 的公告事件与方向 2 的财务指标使用独立 schema，均保留原文位置和文件指纹。

## 财务证据

| 字段 | 含义 |
|---|---|
| evidence_id / document_id | 证据及原始文件身份 |
| company_code / company_name | 公司身份 |
| report_year | 来源报告年度 |
| period_year / period_start / period_end | 数值对应的实际期间 |
| period_kind / duration_months / period_basis | annual、half、quarter、instant；期间长度；累计、单季或余额 |
| metric / value / unit | 指标、原始值与单位 |
| normalized_value / normalized_unit | 金额统一元；每股和百分比保留自身单位 |
| currency / scope / adjustment | 币种、合并或归母口径、调整前后状态及依据 |
| source_file / source_sha256 / source_url | 原文件、指纹及原始来源 |
| page / page_label / value_bbox / year_header | PDF 页序、印刷标签、值位置及期间表头 |
| issues | 缺单位、缺币种、冲突等待复核原因 |

原有年报证据保留兼容字段。存量指标依指标类型识别，不将年报“总资产”当成可加流量；新期间报告的余额标为 instant。

同比只比较同公司、指标、币种、口径和上年对应期间。环比只比较相邻完整单季。二季度流量 = 半年累计 − 一季度累计，三季度流量 = 前三季累计 − 半年累计。缺少上一累计期间时不生成单季值；EPS、ROE 和资产余额不拆差。

金额换算、增长率和倍数均使用 Decimal。零或负基数保留特殊状态，不输出通常意义的增长率或正倍数。原披露同比按其小数位 HALF_UP，保留显示值舍入导致的 1 ULP 容差；草稿约数另按明确的约数规则。

## 公告事件

质押必填：质押股东、股数、质权人、起始日；中标必填：项目、主体、金额；股权变动必填：转让方、受让方、股数、变动日。事件还保存可提取的比例、用途、期限等字段。

每个字段具有原值、规范值、单位、状态及 evidence 列表。状态包括 extracted、missing、conflict、needs_review。同一股东的不同表格交易行保留为独立事件；只有唯一可关联的正文与表格才合流。缺失不补猜，冲突保留双方证据。预估中标金额不冒充最终合同金额。

OCR 使用可选的本地语言数据。扫描公告按 words 几何行重建标签，所有识别字段转复核；当前不承诺任意扫描复杂表或低清照片的准确解析。扫描财报尚未接入财务主链。

## 分析与核查

财务观察包括归母减扣非、差额占比、扣非同比、利润与现金流同比差及连续性；同一历史期间在相邻报告中不同列示的值标为口径变化或重述线索，需查更正说明。

事实是原始字段与可复算结果；推论是待补证据的原因分析框架；模型解释标为未完全核实；不输出投资观点或将信号定性为财务造假。

PE = 明确时点每股价格 / 年度基本 EPS；PB = 每股价格 / 同期间每股净资产；EV/EBITDA 只在完整且同公司、同单位的显式输入下计算。TTM、预测、非正分母、时点或口径未明时转复核。草稿自带价格只用于内部一致性，不声称已核实市场行情；估值时点是否已公开披露报告仍须确认。

引用核查明确区分 PDF 页序和印刷页码。页序超界可确认错误；文件不可用、指纹不同、印刷标签未解析或页内未支持主张分别说明，不自动称来源伪造。页内片段命中不代表整段投资结论成立。

## 模型与执行记录

LLM 负责拆句和在预算内请求受限工具；本地规则校验数字、单位、公司、期间与原句的对应，再计算裁决。单次拆解不提供年报数值；工具循环允许模型读取证据并请求程序比较。模型从不拥有最终裁决权。

轨迹展示实际模型输入输出 JSON、工具参数、结果、门控原因和公式，不生成模型私有思维链。输入及模型响应的凭证检查在持久化和日志输出前执行。运行归档包含全部核心 Python 模块、脚本、界面源码和项目 requirements。

环境、第三方许可、验证结果分别见 [运行说明](../docs/运行说明.md)、[第三方与来源清单](../docs/第三方与来源清单.md)、[赛题修复验收](../docs/赛题修复验收.md)。人工复签和独立盲测尚不能由程序代替。
